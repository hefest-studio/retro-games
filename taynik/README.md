# ТАЙНИК

Оригинальная аркада студии «Гефест» в жанре «исследователь в лабиринте с верёвками» (ранние 8-битные
«гробничные» лабиринты): огромный вертикально-горизонтальный лабиринт, по которому лазишь по свисающим
верёвкам, прыгаешь с одной на другую над кислотой, стреляешь в обитателей и ищешь выход наверх.

**Сеттинг.** Заброшенная водонапорная башня старой мастерской «Гефест». Подмастерье-фонарщик **Светляк**
с пневмопистолетом поднимается с яруса на ярус: подвал, насосная, трубный ярус, котельная, паровой ярус
и, наконец, пространство под баком. Наверху каждого яруса — люк с верёвкой.

## Правила
- **Верёвки.** ↑ рядом с верёвкой — хват, ↑/↓ — подъём/спуск; на верёвке ←/→ (новое нажатие) — прыжок с неё.
  В полёте герой сам хватается за верёвку, через которую пролетает. У края люка ↓ — хват за верёвку вниз.
- **Прыжок** с пола — ↑ (с ←/→ — в сторону): ≈ 44 px вверх, ≈ 64 px вперёд. Падение выше 100 px отнимает силу.
- **Кислота** на полу «коридорных» залов — гибель; над ямами висят одна-две верёвки.
- **Сила** (100): касание обитателя отнимает 15–25 (затем 1,2 с неуязвимости), масленка возвращает 35.
  Сила на нуле — потеря жизни. Жизней 3 (+1 за каждые 10 000 очков, до 5).
- **Пневмопистолет**: пробел / Z / X, по направлению взгляда, дальность ≈ 260 px. Заряды ограничены
  (на старте 8, в начале яруса — не меньше 6), ящик даёт +4 (максимум 15).
- **Обитатели**: ржавые пауки на нитях (качаются вверх-вниз), летучие искры (мечутся по залу),
  капли кислоты с потолка (набухают и падают — пули их не берут), призраки пара (летят к герою сквозь
  стены, 2 попадания), хамелеоны-механизмы (сливаются с полом, проявляются рядом и ползут к герою, 2 попадания).
- **Находки**: камни (200) и детали (100), ящики зарядов, масленки, **карты-подсказки** (на 1,6 с
  показывают кусок лабиринта вокруг героя, путь к люку и стрелку, если люк дальше), **фонари** —
  зажёг, и после потери жизни продолжаешь у него.
- **Выход** — подняться по верёвке в люк в потолке верхнего ряда: +1000, +5 за единицу силы, +20 за заряд.
  После 6-го яруса — победа.

## Уровни
6 ярусов, лабиринт растёт от 4×3 до 8×6 залов (зал — 12×8 тайлов по 20 px). Лабиринт генерируется:
остовное дерево по залам (+ петли с 2-го яруса), люки с верёвками между этажами, кислотные ямы, полки.
Затем **проверка достижимости** поиском по тем же правилам физики, что в игре (макро-ходы: шаг, прыжок,
хват, подъём/спуск, прыжок с верёвки); непроходимый вариант отбрасывается, а предметы ставятся только в
достижимые точки. Обитатели вводятся постепенно: капли — со 2-го, призраки — с 3-го, хамелеоны — с 4-го.

## Управление
←→ / AD — шаг · ↑ / W — прыжок, хват и подъём · ↓ / S — спуск · на верёвке ←/→ — прыжок с неё ·
пробел / Z / X — выстрел · P / Esc — пауза · T — тема (modern / retro) · L — язык (RU / EN) · M — звук.
На телефоне — экранная крестовина и кнопка огня, кнопка паузы вверху справа.

## Файлы
| файл | что |
|---|---|
| `index.html` | страница, канва 512×384, тач-кнопки, «← Каталог» |
| `engine.js` | копия `_shared/engine.js` (фреймворк Гефест Arcade v2.2) |
| `js/game.js` | логика без DOM: физика, генерация, достижимость, обитатели, счёт |
| `js/modern.js`, `js/classic.js` | рендеры тем modern (по умолчанию, со светом фонаря) и retro (8-бит) |
| `js/ui.js` | HUD, баннеры, всплывашки, карта-подсказка, подгонка канвы |
| `js/main.js` | сборка на движке: сцены, ввод, события → звук/эффекты |
| `js/i18n.js`, `js/audio.js`, `js/music.js` | строки RU/EN, SFX, оригинальная музыкальная тема |
| `tests/engine.test.mjs`, `tests/bot.mjs` | автотесты и боты |

## Проверка
```
node taynik/tests/engine.test.mjs      # FAST=1 — без долгого прогона «человеческого» бота
node tools/smoke.mjs
```
Тесты: физика (ходьба, прыжок, верёвки, перелёт между верёвками, люк, кислота, падение), скролл камеры,
стрельба и заряды, поведение каждого обитателя, энергия/жизни/фонари, карты-подсказки, выход и переход,
генерация и достижимость (8 сидов × 6 уровней), прохождение каждого уровня «идеальным» ботом,
баланс «человеческим» ботом (уровень 1 ≥ 90 %, вся игра ~20–40 %), строки, музыка, страница, правило имён.
