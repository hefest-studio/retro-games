# ЗАСЛОН · Скролл-шутер

Оригинальный вертикальный скролл-шутер студии **«Гефест»** на фреймворке Гефест Arcade v2.2.
Чистый HTML5/Canvas, без сборки, CDN и внешних ассетов — открывается как `zaslon/index.html` (и по `file://`).

Корабль держит **заслон** — энергобарьер у нижнего края экрана. Враги идут волнами сверху;
каждый, кто дошёл до барьера, отнимает его прочность. Барьер упал — игра окончена, даже если корабли ещё есть.
5 секторов, в конце каждого — свой босс; между секторами — **мастерская**, где металлолом со сбитых врагов
превращается в апгрейды.

- **Оружие** (переключается капсулами из Носителя; капсула меняет вид по кругу — лови нужный):
  **Искра** — веер, **Луч** — непрерывный, **Дробь** — разлёт вблизи. У каждого 3 уровня.
- **Боковые модули** (до 2), **энергощит** корабля (гасит попадания, восстанавливается), **мега-бомба** (B / X / ✹).
- **Враги:** Клещ, Стриж (пикирует на корабль), Ткач (зигзаг, веер пуль), Таран (броня), Носитель (несёт капсулу).
- **Боссы:** Жернов (кольца пуль), Клешня (следит и выпускает клещей), Улей (стрижи, веер, спираль),
  Маятник (качается и бьёт столбом-лучом после предупреждения), Горн (финал, три фазы).
- **Темы:** modern (по умолчанию) и retro 8-бит — `T`. **Языки:** RU/EN — `L`. **Звук/музыка:** `M`. **Пауза:** `P`/`Esc`.
- Управление: стрелки / WASD — полёт, Пробел — огонь (удержание), B / X — бомба. В мастерской: ↑↓ + Пробел/Enter или тап по строке.
  На телефоне — крестовина, ● огонь, ✹ бомба, кнопка паузы.
- Параллакс (3 слоя звёзд + фермы станции), частицы и кольца взрывов, оригинальный трек (ми минор, 144 bpm), свои SFX; рекорд — `arcade.best.zaslon`.

Автотесты логики: `node zaslon/tests/engine.test.mjs` (29/29, ~40 с, включая баланс по «человеческому» боту).

## Баланс

Проверяется ботом `tests/bot.mjs`, который играет как человек: видит только экран (`state()`), жмёт только
`setDir`/`setFire`/`bomb` и пункты мастерской; реагирует на картинку 150–250 мс давности, решает ~12 раз в секунду,
двигается в 8 направлениях, следит за угрозами в радиусе ~190 px, скорость каждой пули оценивает «на глаз»
(±12%, ±6°), руку доводит с разбросом ±8 px. Огонь зажат всё время, бомба — в панике, в мастерской —
простая очередь покупок (починка при низком заслоне, оружие, модуль, щит…). 100 детерминированных партий (сиды 1..100).

| Метрика (бот 150–250 мс, сиды 1..100) | значение | цель |
|---|---|---|
| 1-й сектор пройден | 100% | ≥ 90% |
| все 5 секторов пройдены | 29–37% | 20–40% |
| потерь кораблей на сектор (1/2/3/4/5) | ≈ 0.02 / 0.2–0.3 / 0.6 / 0.8–1.0 / 1.1–1.3 | рост к 4–5 |
| потеря заслона за сектор, % (1 → 5) | ≈ 2 → 30 | давление растёт |

Чувствительность к реакции (все 5 секторов, 60 партий): 120–180 мс — 53%, 150–250 мс — ~30%, 200–300 мс — 17%.
Рычаги сложности по сектору (через `g.difficulty`): скорость и прочность врагов, скорость и частота вражеских пуль,
темп и плотность волн; экономика лома (шанс выпадения, цены) держит полную прокачку к 3–4-му сектору.
