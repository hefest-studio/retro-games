# ПОДКОП · Лестницы и ямы

Оригинальная аркада-лабиринт студии «Гефест»: бегай по ярусам, лазай по **лестницам** и
перебирайся по **канатам**, **копай ямы-ловушки** в кирпиче — страж проваливается и остаётся
замурованным, когда яма зарастёт. Собери **всё золото** — над выходом проявится лестница наверх.
10 уровней ручной работы: от «Разминки» до «Последнего забоя» с тремя стражами.

Работает на фреймворке **Гефест Arcade v2** (`engine.js` — копия `_shared/engine.js`) «оболочкой»:
движок даёт меню, паузу, темы **retro / modern** (modern по умолчанию), RU/EN, звук и музыку,
счёт и рекорд (`arcade.best.podkop`); родные логика (`js/game.js`), уровни (`js/levels.js`) и
рендер (`js/render.js`: 8-бит и векторный modern) переиспользованы. Раньше игра лежала в папке
СТАРАТЕЛЯ; при первом запуске её прежний рекорд переносится в новый ключ (`js/store-migrate.js`).

## Запуск

Откройте `index.html` (или `python3 -m http.server` из корня репо). Без сборки и сети.

## Управление

| Действие | Клавиши |
|---|---|
| Бег, лестницы | `← → ↑ ↓` или `WASD` |
| Спрыгнуть с каната | `↓` |
| Копать влево / вправо | `Z` / `X` (также `Q` / `E`, `,` / `.`) |
| Копать по взгляду | `Пробел` |
| Пауза / меню | `P` / `Esc`, `Enter` — выбор |
| Язык / тема / звук | `L` / `T` / `M` |

**Тач:** экранные ▲ ◀ ▼ ▶, ⛏◀ / ▶⛏ — копать, II — пауза.

## Правила

- Яма открыта ~4,6 с. Страж, упавший в яму, сидит в ней; когда яма зарастает — гибнет (+150) и
  через несколько секунд возрождается на своём месте. Игрок в зарастающей яме теряет жизнь.
- Кирпич копается только сбоку-снизу от героя и только если над ним не лежит золото/выход.
- Стража не копает, но отлично лазает по лестницам и канатам и идёт по кратчайшему пути.
- 3 жизни; смерть — уровень начинается заново. За уровень +250 и бонус за скорость.
- Все уровни проходимы **без копания** — кирпич нужен только против стражи (проверяет BFS-валидатор).

## Темы

- **modern** — векторная графика: скруглённые блоки, мягкое свечение лестниц и золота.
- **retro** — 8-бит: буфер 448×256 с апскейлом без сглаживания.

**Музыка:** оригинальная тема «подкопа» в ми-миноре (`Arcade.tracks.podkop`, `js/music.js`, API v2.1);
тембр меняется вместе с темой.
