# ПОДКОП · Лестницы и ямы

Оригинальная аркада-лабиринт студии «Гефест»: бегай по ярусам, лазай по **лестницам** и
перебирайся по **канатам**, **копай ямы-ловушки** в кирпиче — страж проваливается и остаётся
замурованным, когда яма зарастёт. Собери **всё золото** — над выходом проявится лестница наверх.
10 уровней ручной работы: от «Разминки» до «Последнего забоя» с тремя стражами.

Работает на фреймворке **Гефест Arcade v2** (`engine.js` — копия `_shared/engine.js`) «оболочкой»:
движок даёт меню, паузу, темы **retro / modern** (modern по умолчанию), RU/EN, звук и музыку,
счёт и рекорд (`arcade.best.podkop`); родные логика (`js/game.js`), уровни (`js/levels.js`) и
рендер (`js/render.js`: 8-бит и векторный modern) переиспользованы. Раньше игра лежала в папке
СТАРАТЕЛЯ; при первом запуске её прежний рекорд переносится в новый ключ (`js/store-migrate.js`).

## Запуск

Откройте `index.html` (или `python3 -m http.server` из корня репо). Без сборки и сети.

## Управление

| Действие | Клавиши |
|---|---|
| Бег, лестницы | `← → ↑ ↓` или `WASD` |
| Спрыгнуть с каната | `↓` |
| Копать влево / вправо | `Z` / `X` (также `Q` / `E`, `,` / `.`) |
| Копать по взгляду | `Пробел` |
| Пауза / меню | `P` / `Esc`, `Enter` — выбор |
| Язык / тема / звук | `L` / `T` / `M` |

**Тач:** экранные ▲ ◀ ▼ ▶, ⛏◀ / ▶⛏ — копать, II — пауза.

## Правила

- Яма открыта ~4,6 с. Страж, упавший в яму, сидит в ней; когда яма зарастает — гибнет (+150) и
  через несколько секунд возрождается на своём месте. Игрок в зарастающей яме теряет жизнь.
- Кирпич копается только сбоку-снизу от героя и только если над ним не лежит золото/выход.
- Стража не копает, но отлично лазает по лестницам и канатам и идёт по кратчайшему пути.
- 3 жизни; смерть — уровень начинается заново. За уровень +250 и бонус за скорость.
- Все уровни проходимы **без копания** — кирпич нужен только против стражи (проверяет BFS-валидатор).

## Темы

- **modern** — векторная графика: скруглённые блоки, мягкое свечение лестниц и золота.
- **retro** — 8-бит: буфер 448×256 с апскейлом без сглаживания.

**Музыка:** оригинальная тема «подкопа» в ми-миноре (`Arcade.tracks.podkop`, `js/music.js`, API v2.1);
тембр меняется вместе с темой.

## Проверка 2026-11 (отложенная игра, площадки)

**Вердикт: на переделку.** Для Яндекс Игр / GamePush в нынешнем виде не подавать (риск отказа как клона, п. 3.6; правило узнаваемости 13.11).
Имён чужих игр в тексте нет, но **итоговая картина — точная калька классики жанра «копай ямы + лестницы + золото»**:

- **Сетка 28×16** — точный размер поля оригинала; ярусы кирпича с лестницами и канатами (hand-over-hand).
- **Ядро механики без изменений:** копать яму сбоку-снизу от героя (Z/X, как в оригинале), стражи падают в яму и замурованы, пока она не зарастёт, затем возрождаются; страж идёт по кратчайшему пути.
- **Фирменная «визитка»:** собрал всё золото → проявляется лестница на выход вверх; выход — над верхним ярусом.
- Структура уровней — ручные «головоломки-ярусы» одного стиля; кирпич копаемый/монолит, золото на полках, 3 стража на финале.
- Облик: белый человечек и красно-розовые стражи, жёлтые лестницы, синий кирпич — отличается от оригинала палитрой, но не настолько, чтобы «не узнаваться».
- Играбельность на тач: ▲◀▼▶ + две кнопки копания + пауза — это 7 кнопок (> 3–4); нужен стик и одна кнопка «копать».
- Техсостояние нормальное: движок v2 «оболочкой», 10 уровней, BFS-валидатор, тесты, миграция рекорда. Подготовка под площадки не делалась. Браузерная проверка не проводилась (вердикт принят по механике и данным).
- Замечание по правилу имён: тест `tests/engine.test.mjs` (стр. ~204) и `js/store-migrate.js` (стр. ~10) собирают старый ключ localStorage старой папки из частей строки (`['lode','runner.'].join('')`). Строка не в явном виде, но по правилу 12.11 лучше хранить миграцию без этого имени (или удалить миграцию — рекорды СТАРАТЕЛЯ ограничены прежней папкой).

### Что нужно, чтобы игра перестала быть клоном (варианты для будущей волны; код не переделывался)

1. **«Подкоп-обвал» — вместо ям рушить опоры.** Герой не роет яму, а подрубает опорные балки/стойки: участок яруса падает вместе с тем, кто на нём стоит (стражи, золото вниз по этажам, сам игрок). Цель — свалить золото в приёмный вагонетчик внизу и собрать врагов под обломками. Нет лестниц-выхода «проявленной» после золота; выход — вагонетка/подъёмник, заводимый рычагом. Сетка другая (напр. 20×12, вертикальный скролл-шахта).
2. **Пазл-шахта с водой/песком.** Копаешь тоннели в сыпучем грунте (свободная форма, не клетки-ямы), песок осыпается по физике, враги — подвижные существа (кроты, летучие мыши) с разными правилами, а не «страж с поиском пути». Золото → самоцветы, которые нужно спустить по жёлобу; лестницы заменить на выдвижные платформы/лебёдку.
3. **Кооп-пары: «Подкоп вдвоём».** Два героя (копатель и носильщик, 1 игрок меняет их кнопкой), копатель делает ходы только вертикально, носильщик — по ярусам; стражи заменены на ловушки-механизмы по таймеру; цель — довести груз до выхода, не собирая «всё золото».

Любой вариант: другая сетка, другая «визитка» выхода, другой облик героя (не светлая фигурка с акцентным цветом), тач — стик + 1 кнопка.
