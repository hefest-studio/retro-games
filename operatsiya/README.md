# ОПЕРАЦИЯ · Пошаговая тактика отрядом

Оригинальная игра студии **«Гефест»**: пошаговая тактика с видом сверху на сетке, в духе 8-битной эпохи.
Чистый HTML5/Canvas на фреймворке Гефест Arcade v2.2: без сборки, CDN, шрифтов и ассетов из сети,
открывается как `operatsiya/index.html` (в том числе по `file://`).

**Сеттинг.** Ремонтная бригада мастерской «Гефест» — шесть механиков с инструментами-излучателями
(паяльник, клепальник, искровик, резак) — вычищает Завод-Город, захваченный автоматонами **Ржавого Совета**.
Мир вымышленный и мирный: ни армий, ни флагов, ни стран. Подбитый механик не погибает — он **ломается и
уезжает на ремонт** и возвращается к следующей миссии; автоматоны «разбираются».

## Механики
- **Очки действия (ОД).** У каждого бойца свой запас на ход. Шаг — 2 ОД, по диагонали — 3, пригнувшись — +1,
  лестница — +2, дверь на пути — +3 (открывается сама). Выстрел прицельный — 12, навскидку — 7, очередь (3 заряда) — 10,
  шестерня — 8, присесть/встать — 2, перезарядка — 6, подобрать — 3, поворот — 1, ремонт — 4. Неистраченные ОД
  остаются на **реакционный огонь** в ход противника.
- **Обзор и туман.** Боец видит конусом 160° по направлению взгляда (соседнюю клетку — всегда) на 11 клеток.
  Враг виден, только если его видит кто-то из отряда; разведанные клетки остаются под туманом, последние известные
  позиции противника помечены «?». Ход останавливается, когда замечен новый противник.
- **Линия видимости** симметрична (если ты видишь врага — он видит тебя): стены, кирпич и закрытые двери её
  перекрывают, ящики — нет; диагональный зазор между двумя стенами закрыт.
- **Укрытия.** Ящик рядом с целью со стороны стрелка — полуукрытие (−22% к шансу), угол стены — полное (−40%),
  присед — ещё −8%. В упор укрытие не спасает.
- **Высота.** Балконы котельной поднимаются по лестницам: сверху +12% к шансу и укрытие цели хуже на ступень,
  снизу балкон прикрывают перила (не меньше полуукрытия).
- **Шанс попадания** — меткость бойца + инструмент + режим, минус штраф за дистанцию сверх рабочей дальности
  инструмента, минус укрытие и присед, плюс высота; пределы 5–95%. Шанс показывается при наведении на цель.
- **Разрушения.** Кирпичные стены, ящики и двери имеют прочность: по ним можно стрелять (режим выстрела + щелчок по
  стене), их рушат шестерни, промахи бьют в укрытие цели. Пролом — новый проход.
- **Шестерня-граната** летит по дуге до 4 + выносливость/12 клеток, промах уводит на соседнюю клетку, взрыв 3×3
  (6 в центре, 4 рядом) задевает и своих.
- **Перегрев** (свой вариант паники): каждое попадание копит жар (меньше у выносливых). В начале хода при жаре ≥ 50
  боец теряет часть ОД, при ≥ 100 «закипает» и пропускает ход; жар остывает каждый ход, ремкомплект снимает его.
- **Снаряжение перед миссией:** отряд (4–6 из шести), инструмент, шестерни, ремкомплекты, обоймы. Вес сверх
  предела (6 + выносливость/10) снимает 2 ОД за единицу.
- **Бойцы со статами:** меткость, ОД, выносливость, прочность. **Опыт** между миссиями: +3 уцелевшему, +1 за попадание,
  +2 за разобранный автоматон; уровни поднимают все статы.
- **ИИ Ржавого Совета:** часовые ждут в укрытии и поднимают тревогу (видят бригаду, слышат выстрелы и шаги),
  выбирают клетку с укрытием и линией огня, обходят укрытие цели, бросают шестерни в группу, перезаряжаются,
  в конце хода приседают; оставшиеся ОД — на реакционный огонь. Автоматоны: шестерёнчик, клепальщик, котёл,
  метатель и Председатель.
- **7 миссий:** «Проходная» (зачистка), «Мастер Ефим» (спасение), «Ядро цеха» (взлом), «Насосная» (удержание
  с подкреплениями), «Грузовой лифт» (эвакуация), «Балконы котельной» (зачистка с высотой), «Сердце Совета»
  (Председатель). Лимит ходов у каждой; проваленную миссию можно переиграть.
- **Горячий стул:** две команды на одном устройстве (бригада против автоматонов) на зеркальной арене; между ходами —
  экран «передайте устройство», чужие позиции скрыты туманом.
- **Сохранение:** кампания — `arcade.operatsiya.save`, бой — в начале каждого хода бригады (`arcade.operatsiya.battle`,
  «Продолжить» в меню возвращает прямо в бой), сложность — `arcade.operatsiya.diff`, рекорд — `arcade.best.operatsiya`.

## Управление
| | Мышь / клавиатура | Тач |
|---|---|---|
| Выбрать бойца | щелчок по бойцу или строке списка, Tab / Q / E | тап |
| Идти | щелчок по полу (путь и цена показаны при наведении) | тап — путь, второй тап — идти |
| Выстрел | щелчок по видимому врагу; 1/2/3 — прицельный/навскидку/очередь | тап — шанс, второй тап — огонь |
| Выстрел по стене | 1/2/3, затем щелчок по стене или ящику | кнопка, затем тап ×2 |
| Шестерня | G, затем щелчок по клетке | кнопка, затем тап ×2 |
| Присесть / перезарядка / действие | C / R / F (дверь, подобрать, освободить, взлом, эвакуация) | кнопки панели |
| Поворот / ремонт | Z, затем клетка / K | кнопки панели |
| Конец хода | N | кнопка «Конец хода» |
| Курсор | стрелки / WASD, пробел или Enter — щелчок | — |

P/Esc — пауза, T — тема (modern/retro), L — язык (RU/EN), M — звук. ПКМ — отменить режим.

## Файлы
- `index.html` — страница, тач-кнопки, порядок скриптов; `css/style.css` — оформление страницы.
- `engine.js` — копия `_shared/engine.js` (синхронизирует `build.sh`).
- `js/missions.js` — карты 7 миссий и арены; `js/game.js` — логика боя без DOM (`OPERATSIYA.Game`, `OPERATSIYA.logic`);
  `js/campaign.js` — бригада, опыт, снаряжение, сохранение (`OPERATSIYA.Camp`); `js/render.js` — поле, HUD, панели;
  `js/ui.js` — снаряжение, разбор, передача хода, DOM; `js/modern.js` / `js/classic.js` — палитры тем;
  `js/audio.js` — SFX; `js/music.js` — оригинальная тема (`Arcade.tracks.operatsiya`); `js/i18n.js` — RU/EN;
  `js/main.js` — сборка, сцены и ввод.
- `tests/engine.test.mjs` — автотесты, `tests/bot.mjs` — бот-командир. Контракт модулей — `CONTRACT.md`.

Тесты: `node operatsiya/tests/engine.test.mjs` (`QUICK=1` — без партий бота).
