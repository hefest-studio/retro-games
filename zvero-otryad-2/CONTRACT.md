# CONTRACT · ЗВЕРО-ОТРЯД 2

Технический контракт игры. Все модули соблюдают его дословно, чтобы файлы можно
было менять независимо. Игра офлайн: чистый HTML/CSS/Canvas, без сборки, без
CDN/npm/сети, без внешних картинок/шрифтов/звуков. Открывается двойным кликом по
`index.html` (`file://`). Это продолжение: тот же движок, что и в `zvero-otryad`,
с новыми уровнями-«погребами», ледяной палитрой и пространством имён `ZVERO2`.

> **v2 (оболочка Гефест Arcade).** С волны 2 `index.html` — оболочка на движке v2:
> `engine.js` → `js/music.js` → `js/coop.js` → `js/i18n.js` → `js/game.js` → `js/classic.js` → `js/modern.js`
> + инлайн-скрипт (меню/пауза/темы/язык/счёт — движок; кооп-ввод — `js/coop.js`).
> `js/audio.js`, `js/ui.js`, `js/main.js`, `css/style.css` используются только старой страницей `legacy.html`,
> для неё §0 и §7 ниже остаются в силе. Раскладка в v2: И1 — стрелки, И2 — WASD (см. README).

## §0 · Структура и порядок загрузки

```
index.html
css/style.css
js/i18n.js      → js/audio.js → js/game.js → js/classic.js
→ js/modern.js  → js/ui.js    → js/main.js
```

`index.html` подключает ровно эти 7 скриптов строго в указанном порядке.
Один `<canvas id="game" width="960" height="600">`.

## §1 · Пространство имён

Классические `<script>` (не ES-модули). Общий глобальный объект:

```js
(function (global) {
  'use strict';
  var Z = global.ZVERO2 = global.ZVERO2 || {};
  // ...
})(typeof window !== 'undefined' ? window : globalThis);
```

Никаких `import`/`export`, `fetch`, внешних URL. Комментарии — на русском.
Экспортируемые поля: `Z.i18n`, `Z.t`, `Z.audio`, `Z.Game`, `Z.consts`,
`Z.classic`, `Z.modern`, `Z.ui`.

## §2 · i18n (`js/i18n.js`)

- `Z.i18n = { lang, strings }`, язык по умолчанию `ru` (+ `en`).
- `Z.t(key)` → строка текущего языка. Весь UI-текст только через `Z.t`.

## §3 · Аудио (`js/audio.js`)

- WebAudio-чиптюн: pulse/square/triangle/sawtooth + шум. Оригинальная мажорная
  мелодия + SFX: `jump, grab, throw, smash, pickup, door, hurt, bosshit,
  gameover, win`. Файлов аудио нет.
- API: `unlock, startMusic, stopMusic, setSound, setMusic, isOn, sfx(name)`.

## §4 · Движок (`js/game.js`) — DOM-free, детерминированный

- `Z.Game({ hi, twoP, onEvent })` → объект-API. Мир: клетка 30 px, 20 рядов,
  видимая область 960×600, камера скроллит по горизонтали за средней точкой
  живых игроков. Края карты — стены (герой не уходит за левый/правый край).
- Методы: `start()`, `update(dt)` (алиас `step`), `state()`,
  `setHeld(pi,'left'|'right',bool)`, `jump(pi)`, `action(pi)`, `setTwoP(bool)`,
  `isTwoP()`, `pause()`, `isPaused()`, `phase()`, `setHi(v)`.
- Фазы: `title · play · levelclear · gameover · win` + пауза.
- `onEvent(type, data)` уведомляет о звуковых событиях и `gameover`/`win`
  (с `{score}`).
- Уровни — массивы строк (`LEVELS`). Легенда: `#` кирпич, `=` платформа,
  `P` старт (И2 ставится рядом с И1: ближайшая свободная клетка с опорой, сначала +28 px вправо), `c` ящик, `W` ходок, `F` летун, `o` звезда-друг,
  `D` дверь выхода, `B` босс.
- Ко-оп: 1–2 игрока (`Пыж` id 0, `Тяпа` id 1) с общим запасом жизней; павший
  герой возрождается рядом с напарником.
- Кооп-«поводок» (оба героя всегда в кадре): живые герои не расходятся дальше
  `LEASH_SPAN = VIEW_W − 2·LEASH_PAD` = 880 px (от левого края левого до правого края
  правого) — движение по X урезается до упора, без телепорта; `player.leashed` = упёрся
  в этом шаге. Камера — по середине пары, поэтому оба в кадре с отступом ≥ 40 px.
  `Z.consts` отдаёт `LEASH_PAD`, `LEASH_SPAN`, `LEVELS` (число цехов) для тестов.
- Механика: `action(pi)` хватает ближайший ящик (радиус ~44 px) или бросает
  тот, что в руках, по направлению взгляда; брошенный ящик сбивает врага/босса и
  разбивается о стену; покоящийся ящик — платформа.
- Босс: HP-полоса, урон только брошенными ящиками; при HP 0 открывается дверь.
- `state()` отдаёт живой объект состояния (сетка, игроки, ящики, враги, босс,
  пикапы, частицы, дверь, камера, очки, жизни и т. д.). Движок не трогает DOM.

## §5 · Рендереры

Оба рисуют один и тот же мир каждый кадр через `draw(ctx, state)` и защищены от
пустого состояния (нет сетки → только фон).

- `js/classic.js` — `Z.classic`: честный 8-бит. Внутренний буфер половинного
  разрешения, `imageSmoothingEnabled = false`, апскейл, ограниченная палитра.
  Режим по умолчанию при старте.
- `js/modern.js` — `Z.modern`: «неон» — свечение, градиенты, параллакс.

## §6 · Оверлеи (`js/ui.js`)

`Z.ui`: `show(name)`, `hideAll()`, `applyI18n()`, `setOver(score,hi)`,
`setWin(score,hi)`. DOM-оверлеи: `ovTitle, ovPause, ovOver, ovWin`.

## §7 · Загрузчик (`js/main.js`)

- Boot, цикл `requestAnimationFrame` (тело обёрнуто в `try/catch`), ввод по
  `e.code` для двух игроков.
- Управление: игрок 1 — `←→`/`↑`/`Space`; игрок 2 — `A D`/`W`/`Shift`;
  `G` графика, `M` звук, `L` язык, `P` пауза, `C`/`1`/`2` игроки, `Enter` старт.
  Экранные кнопки для телефона (игрок 1).
- `localStorage` (в `try/catch`): рекорд + язык/звук/графика/число игроков. Ключи `localStorage` с префиксом `zo2-`.
  **Графика при каждой загрузке принудительно ретро (8-бит).**
- Отладочный хук: `window.__ZVERO2 = { startGame, setGfx, setLang, setTwoP, tick, game }`.

## §8 · Качество

Запускается без ошибок в консоли: заголовок → игра (бег/прыжок/захват/бросок,
убийство врага ящиком) → дверь → следующий погреб → потеря всех жизней → game over →
рестарт; финальный погреб с боссом → победа. Оба режима графики рисуют полную сцену,
оба языка, 1 и 2 игрока. Канва масштабируется под экран. Проходит
`node tools/smoke.mjs` и `node tests/engine.test.mjs`.
