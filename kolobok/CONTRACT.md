# CONTRACT · КОЛОБОК

Технический контракт игры. Все модули соблюдают его дословно, чтобы файлы можно
было менять независимо. Игра офлайн: чистый HTML/CSS/Canvas, без сборки, без
CDN/npm/сети, без внешних картинок/шрифтов/звуков. Открывается двойным кликом по
`index.html` (`file://`).

## §0 · Структура и порядок загрузки

```
index.html
css/style.css
js/i18n.js      → js/audio.js → js/game.js → js/classic.js
→ js/modern.js  → js/ui.js    → js/main.js
```

`index.html` подключает ровно эти 7 скриптов строго в указанном порядке. Один
`<canvas id="game" width="960" height="600">`.

## §1 · Пространство имён

Классические `<script>` (не ES-модули). Общий глобальный объект:

```js
(function (global) {
  'use strict';
  var K = global.KOLOBOK = global.KOLOBOK || {};
  // ...
})(typeof window !== 'undefined' ? window : globalThis);
```

Никаких `import`/`export`, `fetch`, внешних URL. Комментарии — на русском.

Экспортируемые поля: `K.i18n`, `K.t`, `K.audio`, `K.Game`, `K.consts`,
`K.classic`, `K.modern`, `K.ui`.

## §2 · i18n (`js/i18n.js`)

- `K.i18n = { lang, strings }`, язык по умолчанию `ru` (+ `en`).
- `K.t(key)` → строка текущего языка. Весь UI-текст только через `K.t`, в
  рендерерах нет захардкоженных строк.

## §3 · Аудио (`js/audio.js`)

- WebAudio-чиптюн: pulse/square/triangle/sawtooth + шум. Оригинальная короткая
  мелодия + SFX: `jump, berry, pickup, door, plank, splash, nope, warp, hurt,
  gameover, win`. Файлов аудио нет.
- API: `unlock, startMusic, stopMusic, setSound, setMusic, isOn, sfx(name)`.

## §4 · Движок (`js/game.js`) — DOM-free, детерминированный

- `K.Game({ hi, onEvent })` → объект-API. Мир: клетка 40 px, 24×15 клеток,
  поляна = один экран 960×600 (камера не скроллит — флип-скрин).
- Методы: `start()`, `update(dt)` (алиас `step`), `state()`,
  `setHeld('left'|'right', bool)`, `jump()`, `use()`, `pause()`, `isPaused()`,
  `phase()`, `setHi(v)`.
- Фазы: `title · play · warp · dying · gameover · win` + пауза.
- `onEvent(type, data)` уведомляет о звуковых событиях и `gameover`/`win`
  (с `{score}`).
- Поляны — массивы строк (`ROOMS`), связи — `ADJ` (`left/right/up/down` →
  `{ room, x?, y? }`). Легенда: `#` земля, `=` платформа, `D` калитка (ключ),
  `~` речка (гибель; доска → `=`), `^` костёр (гибель; ведро убирает), `*`
  ягода, `k` ключ, `p` доска, `u` ведро, `X` лиса, `G` дом (финиш), `P` старт.
- Инвентарь (`bag`) — до 3 предметов (`key`/`plank`/`bucket`). `use()` применяет
  подходящий предмет ко всему препятствию текущей поляны. Победа: собрать все
  ягоды (`berries === totalBerries`) и коснуться дома.
- `state()` отдаёт живой объект состояния (сетка, игрок, лисы, пикапы, частицы,
  дом, сумка, ягоды, жизни, фаза и т. д.) — его читают рендереры и `main.js`.
  Движок не трогает DOM.

## §5 · Рендереры

Оба рисуют один и тот же мир каждый кадр через `draw(ctx, state)`.

- `js/classic.js` — `K.classic`: честный 8-бит. Внутренний буфер половинного
  разрешения, `imageSmoothingEnabled = false`, апскейл, ограниченная палитра.
  Это режим по умолчанию при старте.
- `js/modern.js` — `K.modern`: «неон» — свечение, градиенты, параллакс,
  светлячки.
- Оба защищены от неинициализированного состояния (пустая сетка/нет игрока).

## §6 · Оверлеи (`js/ui.js`)

`K.ui`: `show(name)`, `hideAll()`, `applyI18n()`, `setOver(score,hi)`,
`setWin(score,hi)`. DOM-оверлеи: `ovTitle, ovPause, ovOver, ovWin`.

## §7 · Загрузчик (`js/main.js`)

- Boot, цикл `requestAnimationFrame` (тело обёрнуто в `try/catch`, чтобы одна
  ошибка не убила цикл), ввод по `e.code`.
- Управление: `←→`/`A D` — катиться; `Space`/`↑`/`W` — прыжок; `E`/`↓`/`S` —
  применить предмет; `G` — графика; `M` — звук; `L` — язык; `P` — пауза;
  `Enter` — старт/рестарт. Экранные кнопки для телефона.
- `localStorage` (в `try/catch`): рекорд + настройки языка/звука/графики.
  **Графика при каждой загрузке принудительно ретро (8-бит).**
- Отладочный хук: `window.__KOLOBOK = { startGame, setGfx, setLang, tick, game }`.

## §8 · Качество

Запускается без ошибок в консоли: заголовок → игра (катись/прыгай/применяй
предметы) → переход между полянами (флип-скрин) → решение головоломок (ключ,
доска, ведро) → гибель от опасности → возврат на начало поляны → потеря всех
жизней → game over → рестарт; все ягоды + дом → победа. Оба режима графики
рисуют полную сцену. Канва масштабируется под экран (мобильная вёрстка).
Версия 1.0.0.
