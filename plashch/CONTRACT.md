# CONTRACT · ПЛАЩ

Технический контракт игры. Все модули соблюдают его дословно, чтобы файлы
можно было менять независимо. Игра офлайн: чистый HTML/CSS/Canvas, без сборки,
без CDN/npm/сети, без внешних картинок/шрифтов/звуков. Открывается двойным
кликом по `index.html` (`file://`).

## §0 · Структура и порядок загрузки

```
index.html
css/style.css
js/i18n.js      → js/audio.js → js/game.js → js/classic.js
→ js/modern.js  → js/ui.js    → js/main.js
```

`index.html` подключает ровно эти 7 скриптов строго в указанном порядке.
Один `<canvas id="game" width="960" height="600">`.

## §1 · Пространство имён

Классические `<script>` (не ES-модули). Общий глобальный объект:

```js
(function (global) {
  'use strict';
  var P = global.PLASHCH = global.PLASHCH || {};
  // ...
})(typeof window !== 'undefined' ? window : globalThis);
```

Никаких `import`/`export`, `fetch`, внешних URL. Комментарии — на русском.

Экспортируемые поля: `P.i18n`, `P.t`, `P.audio`, `P.Game`, `P.consts`,
`P.classic`, `P.modern`, `P.ui`.

## §2 · i18n (`js/i18n.js`)

- `P.i18n = { lang, strings }`, язык по умолчанию `ru` (+ `en`).
- `P.t(key)` → строка текущего языка. Весь UI-текст только через `P.t`,
  в рендерерах нет захардкоженных строк.

## §3 · Аудио (`js/audio.js`)

- WebAudio-чиптюн: pulse/square/triangle/sawtooth + шум. Оригинальная
  «ночная» мелодия в до-миноре + SFX: `jump, shoot, grapple, explode,
  pickup, medkit, bosshit, door, hurt, gameover, win`. Файлов аудио нет.
- API: `unlock, startMusic, stopMusic, setSound, setMusic, isOn, sfx(name)`.

## §4 · Движок (`js/game.js`) — DOM-free, детерминированный

- `P.Game({ hi, onEvent })` → объект-API. Мир: клетка 30 px, 20 рядов,
  видимая область 960×600, камера скроллит по горизонтали.
- Методы: `start()`, `update(dt)` (алиас `step`), `state()`,
  `setHeld('left'|'right'|'up'|'down', bool)`, `jump()`, `shoot()`,
  `grapple()`, `pause()`, `isPaused()`, `phase()`, `setHi(v)`.
- Фазы: `title · play · dying · levelclear · gameover · win` + пауза.
- `onEvent(type, data)` уведомляет о звуковых событиях и
  `gameover`/`win` (с `{score}`).
- Механики: бег/прыжок (гравитация + платформы), сюрикены, **присед**
  (высота 28→16, уклон от пуль) и **крюк-кошка** (маятник на потолочных
  якорях: раскачка `←/→`, подтяг/спуск `↑/↓`, отцеп прыжком или `grapple()`).
- Здоровье: 3 деления на жизнь, аптечки восполняют; 3 жизни.
- Уровни — массивы строк (`LEVELS`). Легенда: `#` кирпич, `=` платформа,
  `P` старт, `G` бандит-ходок, `S` стрелок, `F` летун, `H` потолочный крюк,
  `c` монета, `m` аптечка, `D` дверь выхода, `B` босс (финальная арена).
- `state()` отдаёт живой объект состояния (сетка, игрок с полями
  `crouch`/`grapple`, пули игрока и врагов, враги, пикапы, частицы, якоря,
  дверь, босс, камера, очки, жизни, hp и т. д.) — его читают рендереры и
  `main.js`. Движок не трогает DOM.

## §5 · Рендереры

Оба рисуют один и тот же мир каждый кадр через `draw(ctx, state)` и защищены
от неинициализированного состояния (`if (!st || !st.grid) return;`).

- `js/classic.js` — `P.classic`: честный 8-бит. Внутренний буфер половинного
  разрешения, `imageSmoothingEnabled = false`, апскейл, ограниченная палитра.
  Режим по умолчанию при старте.
- `js/modern.js` — `P.modern`: «неон» — свечение, градиенты, параллакс города.

## §6 · Оверлеи (`js/ui.js`)

`P.ui`: `show(name)`, `hideAll()`, `applyI18n()`, `setOver(score,hi)`,
`setWin(score,hi)`. DOM-оверлеи: `ovTitle, ovPause, ovOver, ovWin`.

## §7 · Загрузчик (`js/main.js`)

- Boot, цикл `requestAnimationFrame` (тело обёрнуто в `try/catch`, чтобы
  ошибка кадра не уронила цикл), ввод по `e.code`.
- Управление: `←→`/`A D` — бег; `↓`/`S` — присед; `Space`/`↑`/`W` — прыжок;
  `J`/`X` — сюрикен; `K`/`Shift` — крюк; `G` — графика; `M` — звук;
  `L` — язык; `P` — пауза; `Enter` — старт/рестарт. Экранные кнопки для телефона.
- `localStorage` (в `try/catch`): рекорд + настройки языка/звука/графики.
  **Графика при каждой загрузке принудительно ретро (8-бит).**
- Отладочный хук: `window.__PLASHCH = { startGame, setGfx, setLang, tick, game }`.

## §8 · Качество

Запускается без ошибок в консоли: заголовок → игра (бег/прыжок/сюрикен,
присед от пуль, крюк-кошка, убийство врага) → дверь → следующий квартал →
финальный босс (Барон) → победа; потеря всех жизней → game over → рестарт.
Оба режима графики рисуют полную сцену. Канва масштабируется под экран
(мобильная вёрстка). Автотесты: `node plashch/tests/engine.test.mjs`.
