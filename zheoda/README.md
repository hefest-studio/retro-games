# ЖЕОДА · Рудознатка в пещерах

Оригинальная игра студии **«Гефест»** — платформер по пещерам-уровням в жанре «собери все кристаллы
на уровне и уйди». Чистый HTML5/Canvas на фреймворке Гефест Arcade v2.2: без сборки, CDN, шрифтов и
ассетов из сети, открывается как `zheoda/index.html` (в том числе по `file://`).

Героиня — **Друза**, геолог-рудознатка мастерской «Гефест»: каска с фонарём, рабочая куртка мастерской,
**заводной бластер**. Пещеры — разрезы **жеод**, выстланные кристаллами. На каждом уровне (1–2 экрана,
плавный скролл камеры) нужно собрать **все кристаллы** — тогда открывается **выход**.

## Механики

| Элемент | Что делает |
|---|---|
| Кристаллы `*` | все собраны → выход открыт (+100 за кристалл) |
| Рычаг `\` (↓ у рычага) | переключает механизм уровня: **решётки** `\|` открываются, **мосты** `:` появляются (и наоборот) |
| Сфера гравитации `G` | вход в сферу переворачивает тяготение: героиня и обитатели-ходоки «падают» вверх, пока не перевернёшь обратно |
| Лифт `H` | ходит между двумя остановками и стоит на каждой ~1,4 с; несёт стоящего |
| Ключи `r b y` и двери `R B Y` | ключ отпирает всю дверь своего цвета |
| Взрывчатка `d` (↓ — заложить) | фитиль 2 с, взрыв рушит трещиноватые стены `%` рядом, убивает обитателей, ранит героиню ближе 1,5 клетки |
| Бластер | заряды ограничены (старт 6, максимум 12), ящики `a` дают +4 |
| Ложные стены `+` | проходимы — за ними тайники с самоцветами `$`, аптечками `h`, ящиками (+1000 за находку) |
| Шипы `^`, кислота `~`, сталактиты `V` | шипы и сталактит −1 здоровья; кислота — сразу минус жизнь; сталактит срывается, когда проходишь под ним |

**Обитатели** (свои): **хрупень** — ползун в кристальном панцире (разворачивается у края), **светляк** —
светящийся мотылёк, **скакун** — каменный шар, прыгает к героине (2 попадания), **плевун** — каменный бутон,
плюётся камешками по прямой (2 попадания). Ходоки подчиняются гравитации.

**Финал — Исполин**: тяжёлый каменно-кристальный ходок, тоже подчиняется гравитации (перевернёшь — рухнет на
потолок и оглохнет на 1,4 с). Перед залпом ядро вспыхивает — затем звёздный залп осколков; в ярости (меньше
половины) — прыжок с ударной волной по полу. 24 удара, взрывчатка снимает 4; **не заживает** между попытками
героини. После него — победа.

- **Карта жеод (хаб):** 16 уровней в 2 эпизодах (Верхние и Глубинные жеоды) + Исполин; уровни открываются по
  очереди. В меню — пункт «Эпизод: 1/2» (второй — после того, как хоть раз дошёл до 9-го уровня;
  `localStorage` `arcade.zheoda.reached`).
- **Жизни:** 3, у каждой — 3 единицы здоровья (неуязвимость 1,4 с после удара). Потеря жизни — уровень заново.
- **Очки:** кристалл 100, самоцвет 500, тайник 1000, обитатель 200, ключ/ящик/взрывчатка 50, уровень 1000 +
  бонус за время + 2000 за все тайники, Исполин 10000. Рекорд — `arcade.best.zheoda`.
- **Сложность:** скорость обитателей, частота прыжков скакуна и плевков растут от уровня к уровню (`g.difficulty`).
- **Темы:** modern (по умолчанию: тёмные жеоды, мягкий свет фонаря, светящиеся кристаллы) и retro (своя
  16-цветная палитра в духе ранних ПК-адаптеров, крупный пиксель, спрайты из строк-карт) — `T`.
- **Языки:** RU/EN — `L`. **Звук:** `M` (SFX на WebAudio + оригинальная «пещерная» тема ре дорийский, `js/music.js`).

## Управление

| Действие | Клавиши / тач |
|---|---|
| Бег | `← →` / `A D`, кнопки `◀ ▶` |
| Прыжок (дольше держишь — выше) | `↑` / `W` / `Z` / `K`, кнопка `▲` |
| Выстрел (удержание — автоогонь) | `Пробел` / `X` / `J`, кнопка `✦` |
| Рычаг / заложить взрывчатку | `↓` / `S`, кнопка `▼` |
| Карта: выбор / спуск | `← →`, `Пробел` / `Enter` / тап по узлу |
| Пауза | `P`, `Esc`, кнопка `II` |
| Тема / язык / звук | `T` / `L` / `M` |

## Файлы

- `index.html` — страница, канва 640×400, тач-кнопки, ссылка «← Каталог», фавикон студии.
- `engine.js` — копия `_shared/engine.js` (кладётся `build.sh`).
- `js/game.js` — логика без DOM: физика (общая с ботом), уровни (17 ASCII-карт), рычаги, гравитация, лифты,
  ключи, взрывчатка, обитатели, Исполин, хаб (`ZHEODA.Game`, `ZHEODA.logic`).
- `js/ui.js` — общий рендер мира (камера, слои), HUD, карта жеод, баннеры, DOM-обвязка;
  `js/modern.js`, `js/classic.js` — внешний вид тем; `js/audio.js` — SFX; `js/music.js` — трек;
  `js/i18n.js` — строки RU/EN; `js/main.js` — сцены движка, ввод.
- `css/style.css` — стили страницы. `tests/` — тесты и бот.

## Тесты, проходимость и баланс

`node zheoda/tests/engine.test.mjs` (~25 с): карты и механики по уровням, физика (бег, прыжок, карнизы),
кристаллы и выход, рычаг (решётки/мосты), ключи и двери, лифт, сферы гравитации, взрывчатка, бластер и ящики,
обитатели и урон, ловушки, секреты, хаб и открытие уровней, Исполин, рост сложности, музыка, i18n, правило имён.

- **Проходимость:** `tests/bot.mjs` строит граф «стоячих» положений (клетка × гравитация × лифты), рёбра —
  короткие макросы ввода, прогнанные на **настоящей физике** игры. Замыкание по рычагу, ключам и взрывчатке
  доказывает, что все кристаллы и выход каждого уровня достижимы; «идеальный» агент-планировщик проходит
  каждый уровень (без тупиков-ловушек) за 7–32 с.
- **Баланс:** «человеческий» бот — реакция 150–250 мс (видит обитателей и снаряды с задержкой), разброс
  нажатий ±1 кадр, промахи, избегает рискованных прыжков; ввод только `setInput/fire/down`.

| Метрика (бот) | сиды 1..40 (тест) | сиды 101..140 | сиды 201..240 | цель |
|---|---|---|---|---|
| 1-й уровень пройден | 100% | 100% | 100% | ≥ 90% |
| вся игра (16 + Исполин) | 27.5% | 22.5% | 22.5% | ≈ 20–40% (в среднем 24%) |

Главные фильтры — 10-й (Потолок), 14-й (Механизм), 16-й (Сердцевина) и Исполин.
