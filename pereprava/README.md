# ПЕРЕПРАВА

Оригинальная аркада студии «Гефест» на тайминг (жанр «переход дороги и реки»).
Механический жук-курьер **Шуруп** из мастерской «Гефест» носит детали через заводской
проезд и канал в пять ячеек склада на дальнем берегу. 10 смен, после 10-й — победа.

Движок — Гефест Arcade v2.2 (`engine.js`, копия `_shared/engine.js`). Офлайн, без внешних ресурсов.

## Как играть
- **←↑→↓ / WASD** — прыжок на соседнюю клетку (удержание — повтор, нажатие во время прыжка запоминается).
- **Тач:** кнопки ▲◀▼▶ под полем, свайп по полю в любую сторону, короткий тап — прыжок вперёд.
- **P / Esc** — пауза (повторное P — продолжить), **M** — звук, **L** — язык RU/EN, **T** — тема modern/retro, **Enter** — старт.

## Правила
- Поле 15×13 клеток: склад (5 ячеек) · канал (5 полос) · насыпь · проезд (5 полос) · пол мастерской (старт).
- **Проезд:** тележки, погрузчики, мотороллеры, катки и фуры разной длины и скорости; касание — гибель.
- **Канал:** брёвна и плоты везут героя по течению; ныряющие поплавки периодически уходят под воду;
  у сома спина — опора, голова — пасть. В воде без опоры — гибель; унесло за край экрана — гибель.
- **Ячейки склада:** прыжок в свободную ячейку — доставка (+50 и +10 за каждую оставшуюся секунду).
  Стена между ячейками, уже занятая ячейка или ячейка с капканом (с 4-й смены, с миганием-предупреждением) — гибель.
  Все 5 ячеек — смена закрыта (+1000).
- **Таймер** на каждую переправу (30 с на 1-й смене → 24,6 с на 10-й); истёк — гибель.
- **Бонусы:** деталь-приз в ячейке (+200), напарник **Шайба** на бревне (со 2-й смены) — встань рядом,
  чтобы подобрать, и доставь в ячейку (+200). +10 за каждый новый ряд вперёд.
- **Враги:** паук на насыпи (с 3-й смены, два — с 8-й), сом в канале (с 5-й), капканы в ячейках (с 4-й).
- **Жизни:** 3, доп. жизнь каждые 10 000 очков (не больше 5). Рекорд — `localStorage` `arcade.best.pereprava`.
- **Усложнение:** 5 раскладок полос (каждая на 2 смены), чётная смена быстрее (×1,06), 10-я — ×1,18;
  поплавки дольше под водой, таймер короче, больше врагов.

## Файлы
| файл | что |
|---|---|
| `index.html`, `css/style.css` | страница, тач-кнопки, «← Каталог», фавикон студии |
| `js/game.js` | логика без DOM (`PEREPRAVA.Game`, `PEREPRAVA.logic`); мир — чистая функция времени |
| `js/main.js` | сборка на движке: экраны, сцена `play`, ввод (клавиши, кнопки, свайпы) |
| `js/modern.js`, `js/classic.js` | рендеры тем modern (по умолчанию) и retro |
| `js/ui.js` | HUD, полоса таймера, баннеры, всплывашки, DOM-обвязка |
| `js/i18n.js`, `js/audio.js`, `js/music.js` | строки RU/EN, SFX, оригинальный трек |
| `tests/engine.test.mjs`, `tests/bot.mjs` | тесты логики, проходимости, баланса (боты), «Правило имён» |

## Проверка
```
node pereprava/tests/engine.test.mjs        # ~3 мин (боты); FAST=1 — без долгих прогонов
node tools/smoke.mjs
```
Баланс («человеческий» бот: реакция 150–250 мс, ошибка руки, запас по времени): 1-я смена — 100 %,
все 10 — ~25 % (40 партий). Идеальный бот проходит все смены; путь в каждую ячейку на каждой смене существует.

Права: название, герой и персонажи (Шуруп, Шайба), уровни, арт, звуки и музыка — оригинальные работы студии.
