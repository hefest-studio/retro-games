# КАСКАД · Головоломка

Оригинальная головоломка с падающими фигурами от студии **«Гефест»**.
Чистый HTML5/Canvas, без сборки, CDN и внешних ассетов — открывается как `kaskad/index.html`.

Семь фигур из четырёх клеток, вращение с отбросом от стен (wall-kick), запас фигуры,
уровни и ускорение. Складывай полные линии, не дай стакану переполниться.

- **Два стиля:** 8-бит и неон (`G`). **Языки:** RU/EN (`L`). **Звук:** `M`. **Пауза:** `P`.
- Управление: ← → двигать, ↑/X поворот, ↓ мягкий сброс, пробел жёсткий, C/Shift запас.
- Оригинальный чиптюн и SFX на WebAudio, рекорд в localStorage.

Автотесты движка: `node kaskad/tests/engine.test.mjs` (9/9).
