# КАСКАД · Головоломка

Оригинальная головоломка с падающими фигурами от студии **«Гефест»**.
Чистый HTML5/Canvas, без сборки, CDN и внешних ассетов — открывается как `kaskad/index.html`.

Семь фигур из четырёх клеток, вращение с отбросом от стен (wall-kick), запас фигуры,
уровни и ускорение. Складывай полные линии, не дай стакану переполниться.

- **Два стиля:** 8-бит и неон (`G`). **Языки:** RU/EN/TR/ES/PT (`L`, см. «Языки»). **Звук:** `M`. **Пауза:** `P`.
- Управление: ← → двигать, ↑/X поворот, ↓ мягкий сброс, пробел жёсткий, C/Shift запас.
- Оригинальный чиптюн и SFX на WebAudio, рекорд в localStorage.

Автотесты движка: `node kaskad/tests/engine.test.mjs` (23/23).

## Площадки (Яндекс Игры, GamePush) — 11.2026
Название: RU — **КАСКАД**, EN — **CASCADE** (одно внутри языка везде: игра, `<title>` сборки, промо — `promo/kaskad/`).
Реклама за награду (только в сборках с рекламой, движок v2.6): «Ещё один шанс?» на поражении раз за партию — `stack.revive()` очищает верхнюю
половину стакана; бонус в меню паузы «Реклама: −2 нижних ряда» (`stack.clearBottom(2)`, раз за партию, если в стакане ≥ 3 рядов).
Межстраничная — только по нажатию на экране финала. На тач — кнопка «II» (пауза). Чек-лист — `_shared/PLATFORM-CHECKLIST.md`.

## Мета-прогрессия: испытание дня (11.2026)
Чтобы игроки возвращались (метрика «возвраты» рекомендателя Яндекса), без платных преимуществ:
- **Испытание дня** — пункт меню «Испытание дня · ДД.ММ»: у всех игроков одна и та же последовательность фигур на день
  (сид 7-bag = хеш даты, `js/daily.js`). День — по серверному времени площадки (`Platform.serverTime()`, адаптер 1.2) в UTC+3
  (один день для всех, как `g.daily()` движка v2.7); без площадки — местная дата устройства. Правила партии те же, цель — 40 линий.
- **Рекорд дня и серия дней** — на заставке и на экране финала («Новый рекорд дня!», «Серия дней: N»). Хранятся одним числом
  (`arcade.kaskad.daily` = ГГГГММДД·10⁷ + очки, `arcade.kaskad.streak` = ГГГГММДД·10³ + дни) — облако площадки сливает их
  режимом `max` (`g.persist`), свежий день всегда «больше» вчерашнего.
- **Лидерборды** — если адаптер даёт `Platform.leaderboard` (1.2) и таблица доступна: после партии `kaskad` (рекорд) и `kaskadDaily`
  (очки испытания); пункт «Лидеры» на заставке. Таблицы с этими техническими именами нужно создать в консоли Яндекса. Без адаптера — пропускается.
  Ограничение: таблица Яндекса не обнуляется по дням — `kaskadDaily` показывает лучшие результаты испытаний за всё время.
- Тесты: детерминизм по дате (50 фигур, два запуска, соседние дни различны), рекорд дня сохраняется и восстанавливается, слияние `max`,
  серия через границы месяца/года, UTC+3; `lang-x` (5 языков, цикл, сохранение, язык площадки, полнота таблиц). `node kaskad/tests/engine.test.mjs` — 23/23.

## Языки: RU / EN / TR / ES / PT-BR (11.2026)
Яндекс: ≈ 40% трафика — нерусскоязычные, рекомендованы TR / ES / PT. Движок v2.7 знает только ru/en (`LANGS` в `engine.js`),
поэтому три языка добавлены **в игре**, без правки `_shared/`: `js/lang-x.js` (одинаковая копия в kaskad/otboynik/kladka) +
`js/i18n-x.js` (строки). Приём: при TR/ES/PT движок работает в режиме `en` (DOM `data-en`, ссылка на EN-каталог, EN-откат для
строк, которых нет в переводе), а таблица `strings.en` на это время подменяется на «EN + перевод».
- Выбор: `?lang=tr|es|pt` → язык площадки `Platform.lang()` после init (Яндекс 2.14; неизвестный — EN) → сохранённый `arcade.lang.x`
  (только если `arcade.lang = en`; другие игры аркады видят `en` и показывают EN). `L` / пункт «Язык»: RU → EN → TR → ES → PT → RU.
- DOM: `data-tr` / `data-es` / `data-pt` (нет атрибута — `data-en`). Длинные строки: заголовок финала/паузы (`g.overlay`) и подсказка
  под меню уменьшают кегль под ширину холста.
- **Название** в TR/ES/PT — EN-название (CASCADE), внутри каждого языка одно и то же: в игре, `<title>` сборки, обложках, `listing.md`
  (Яндекс 5.1.3). Почему не перевод: (1) одна марка на все нерусские рынки — одни обложки и один A/B-тест на EN/TR/ES/PT;
  (2) словарные переводы (ES/PT «Cascada/Cascata», «Mampostería/Alvenaria», TR «Şelale/Duvarcı») чаще совпадают с чужими играми
  каталога — риск отказа по уникальности названия (05.05.2026) и правилу имён студии (12.11); (3) EN-слово «cascade» понятно и в испанском/португальском (cascada/cascata).
- **Вычитка:** перевод — ИИ; проверен обратным переводом на RU и вторым проходом по терминам (единые слова для механик внутри
  языка, длина под кнопки и холст — Playwright, 5 языков × 2 ориентации × 2 темы, 0 вылезающих строк). **Носитель языка не проверял** —
  перед подачей на TR/ES/PT желательна вычитка носителем (возвраты модерации за ошибки перевода бывают).
- **Нужно от движка** (чтобы убрать `lang-x.js`): языки из ключей `strings` вместо фиксированного `LANGS`; `?lang=` и язык площадки
  для любого языка из таблиц (иначе EN); цикл `L` по всем языкам и подпись «Язык: XX»; `data-<lang>` с откатом на `data-en`; ссылка
  каталога — EN для всех не-RU; `label[lang] || label.en` в `useRewardedBonus`/`usePlayers`; встроенные строки (`rw_*`, `loading`) —
  откат на EN; авто-кегль для `overlay`/подсказок; событие «облако слито» после `g.persist` (сейчас игры читают ключи лениво).
