# КАСКАД · Головоломка

Оригинальная головоломка с падающими фигурами от студии **«Гефест»**.
Чистый HTML5/Canvas, без сборки, CDN и внешних ассетов — открывается как `kaskad/index.html`.

Семь фигур из четырёх клеток, вращение с отбросом от стен (wall-kick), запас фигуры,
уровни и ускорение. Складывай полные линии, не дай стакану переполниться.

- **Два стиля:** 8-бит и неон (`G`). **Языки:** RU/EN/TR/ES/PT (`L`, см. «Языки»). **Звук:** `M`. **Пауза:** `P`.
- Управление: ← → двигать, ↑/X поворот, ↓ мягкий сброс, пробел жёсткий, C/Shift запас.
- Оригинальный чиптюн и SFX на WebAudio, рекорд в localStorage.

Автотесты движка: `node kaskad/tests/engine.test.mjs` (23/23).

## Площадки (Яндекс Игры, GamePush) — 11.2026
Название: RU — **КАСКАД**, EN — **CASCADE** (одно внутри языка везде: игра, `<title>` сборки, промо — `promo/kaskad/`).
Реклама за награду (только в сборках с рекламой, движок v2.6): «Ещё один шанс?» на поражении раз за партию — `stack.revive()` очищает верхнюю
половину стакана; бонус в меню паузы «Реклама: −2 нижних ряда» (`stack.clearBottom(2)`, раз за партию, если в стакане ≥ 3 рядов).
Межстраничная — только по нажатию на экране финала. На тач — кнопка «II» (пауза). Чек-лист — `_shared/PLATFORM-CHECKLIST.md`.
**Движок v2.8 (20.11):** «Без рекламы» (`no_ads`) — пункт в меню и паузе с ценой из каталога площадки, после покупки межстраничной и стики нет,
покупка восстанавливается при каждом запуске; «Наши игры» (только через SDK, если у студии есть другие игры на площадке); ярлык (если площадка
позволяет); просьба об оценке — на выходе с экрана победы или нового рекорда, не раньше 3-й сессии, не чаще раза в 3 сессии. P / Esc на паузе — назад в игру.

## Мета-прогрессия: испытание дня (11.2026)
Чтобы игроки возвращались (метрика «возвраты» рекомендателя Яндекса), без платных преимуществ:
- **Испытание дня** — пункт меню «Испытание дня · ДД.ММ»: у всех игроков одна и та же последовательность фигур на день
  (сид 7-bag = хеш даты, `js/daily.js`). День — по серверному времени площадки (`Platform.serverTime()`, адаптер 1.2) в UTC+3
  (один день для всех, как `g.daily()` движка v2.7); без площадки — местная дата устройства. Правила партии те же, цель — 40 линий.
- **Рекорд дня и серия дней** — на заставке и на экране финала («Новый рекорд дня!», «Серия дней: N»). Хранятся одним числом
  (`arcade.kaskad.daily` = ГГГГММДД·10⁷ + очки, `arcade.kaskad.streak` = ГГГГММДД·10³ + дни) — облако площадки сливает их
  режимом `max` (`g.persist`), свежий день всегда «больше» вчерашнего.
- **Лидерборды** (движок v2.8, именованные таблицы `g.leaderboard.submit(score, { board })`): после партии `kaskad` (рекорд) и `kaskadDaily`
  (очки испытания); после слияния облака (`g.onCloud`) рекорды с другого устройства досылаются. Пункт «Лидеры» на заставке (`g.useLeaderboard`):
  Яндекс — своя сцена движка (топ-10, своё место, переключение «Рекорды» / «Испытание дня»), GamePush — окно площадки. Таблицы с этими
  техническими именами нужно создать в консоли Яндекса (GamePush — числовые поля игрока). Без площадки пункта нет.
  Ограничение: таблица Яндекса не обнуляется по дням — `kaskadDaily` показывает лучшие результаты испытаний за всё время.
- Тесты: детерминизм по дате (50 фигур, два запуска, соседние дни различны), рекорд дня сохраняется и восстанавливается, слияние `max`,
  серия через границы месяца/года, UTC+3; языки (`tests/langs.check.mjs`: 5 языков, цикл, сохранение, миграция, язык площадки, полнота таблиц);
  площадка v2.8 (лидеры, без рекламы, свои игры, ярлык, оценка, облако, P на паузе). `node kaskad/tests/engine.test.mjs` — 23/23.

## Языки: RU / EN / TR / ES / PT-BR (11.2026; с 20.11 — в движке v2.8)
Яндекс: ≈ 40% трафика — нерусскоязычные, рекомендованы TR / ES / PT. С движком v2.8 языки — это просто ключи таблиц `strings` игры
(`STR` в `index.html`); бывшие `js/lang-x.js` и `js/i18n-x.js` удалены. Строки движка (меню, пауза, реклама за награду, «Без рекламы», лидеры) — в движке на 5 языках.
- Выбор (правило движка, `_shared/README.md`, «v2.8»): `?lang=tr|es|pt` → сохранённый `arcade.lang` → язык площадки после init (Яндекс 2.14; не из
  таблиц — EN). `L` / пункт «Язык: XX»: RU → EN → TR → ES → PT → RU. Старое хранение пилота (`arcade.lang = en` + `arcade.lang.x`) движок переносит сам.
- DOM: `data-tr` / `data-es` / `data-pt` (нет атрибута — `data-en`); «← Каталог» для всех не-RU ведёт в EN-каталог. Длинные строки — автоподбор кегля движка.
- **Название** в TR/ES/PT — EN-название (CASCADE), внутри каждого языка одно и то же: в игре, `<title>` сборки, обложках, `listing.md`
  (Яндекс 5.1.3). Почему не перевод: одна марка на все нерусские рынки; словарные переводы чаще совпадают с чужими играми каталога
  (уникальность названия, правило имён студии 12.11).
- **Вычитка:** перевод — ИИ; проверен обратным переводом на RU и вторым проходом по терминам. **Носитель языка не проверял** — перед подачей
  на TR/ES/PT желательна вычитка носителем. Длина строк — Playwright: 5 языков × телефон портрет/ландшафт, ни одна строка меню/паузы/финала не вылезает за холст.
