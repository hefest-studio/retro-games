# ВОЛОК (KETTLEWAKE)

Оригинальная игра студии «Гефест»: медитативное путешествие сбоку без слов. Подмастерье в индиговой рубахе
и кожаном фартуке обслуживает изнутри избу-мастерскую на колёсах, которая идёт северными просторами —
тундра → холмы → река → берег → море → льды — к зимовью. На берегу изба переделывается в судно
(поплавки и гребное колесо), а подо льдами погружается колоколом.

## Как играть
- **Низ:** люк (взять топливо из кучи, когда изба почти стоит), бункер, топка, клапан (стравить пар), рычаг хода (стоп → тихо → полный).
- **Середина:** верстак (заплатка; у берега — поплавки из двух поленьев), балласт (на воде — погружение/всплытие), лебёдка (шлагбаум, завал, спуск на воду).
- **Чердак:** фал паруса (по попутному ветру — быстрее; в шторм — убрать, иначе сломает мачту).
- Давление ≥ 100 дольше 2.5 с — пожар (тушить, держа действие у огня). Корпус 0 — авария и откат на чекпоинт.
- Давление выше 85 даёт «форсаж» — им или парусом берётся крутой подъём.

Управление: стрелки/WASD — ход и лестницы, пробел/E — действие (держать для долгих дел), тап/клик по месту в избе —
подмастерье идёт туда сам и делает дело. P — пауза, T — тема, L — язык, M — звук. Путь сохраняется по чекпоинтам
(`localStorage` `volok.save`), меню «Продолжить путь».

## Файлы
`js/game.js` — логика (чистая, без DOM), `js/render.js` + `js/icons.js` — рендер и пиктограммы (retro — та же сцена
в 1/3 разрешения с развёрткой), `js/audio.js` — SFX и звук машины, `js/music.js` — 7 тем по участкам, `js/main.js` — сборка.
Отладка: `#at=<x>` — начать с точки пути.

## Тесты
`node volok/tests/engine.test.mjs` (с ботом ~30 с; `QUICK=1` — без бота). Бот — `tests/bot.mjs`.
