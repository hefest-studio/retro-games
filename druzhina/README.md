# ДРУЖИНА · Beat 'em up на двоих

Оригинальная игра студии **«Гефест»**: фэнтезийный beat 'em up на «полосе» с глубиной для **1–2 игроков**
за одной клавиатурой, в духе аркад 16-битной эпохи. Чистый HTML5/Canvas на фреймворке Гефест Arcade v2.2:
без сборки, CDN, шрифтов и ассетов из сети, открывается как `druzhina/index.html` (в том числе по `file://`).

Дружина мастерской «Гефест» отбивает **Кузнечный тракт** у железной орды **Чёрного Литейщика**:
шесть этапов — Кузнечный тракт, Деревня Подгорье, Дремучий лес, Переправа, Крепостные стены и Литейная
твердыня, — а между ними (после 1-го, 3-го и 5-го) **привал**, куда крадутся бесы-кладовики с кувшинами.

## Герои
| Герой | Кто | Характер | Магия (уровни 1–4 по числу кувшинов) |
|---|---|---|---|
| **Ждан** | молотобоец | медленный, больше всех здоровья, тяжёлый молот, комбо из 3 | «Горнов жар» — огненные столбы (2/4/6/8 кувшинов) |
| **Сеча** | ратница | быстрая, парные клинки, комбо из 4 | «Вихрь клинков» (1/2/3/4) |
| **Ольха** | лучница-ведунья | стрелы на средней дистанции, посох вблизи | «Цепкие корни» (1/3/5/7) |

В коопе — два разных героя (выбор перед боем, последний выбор запоминается).

## Приёмы
- **Комбо** из 3–4 ударов (последний сбивает с ног), **удар в прыжке**, **бег** (двойное нажатие в сторону) и **удар в беге** — сбивают и щитом не блокируются.
- **Захват**: подойти вплотную к врагу; удар — колено, третий удар — бросок вперёд, удар «от врага» — бросок назад; брошенный сбивает соседей. Громилу не схватить.
- **«Спина»** — удар по обе стороны (прыжок+удар одновременно или отдельная клавиша), тратит немного здоровья, не ниже 1.
- **Магия** бьёт всех врагов на экране; сила растёт с уровнем, кувшины тратятся по порогу уровня.
- **Бесы-кладовики** не дерутся: удар выбивает из мешка кувшин или еду (каравай, пирог).
- **Ездовые ящеры**: враги выезжают на **хвостобое** (хвостом по обе стороны) и **огнедышащем ящере** (пламя вперёд). Удар по седоку выбивает его, ничейного зверя можно оседлать (просто подойти), «спина» в седле — спешиться; удар по наезднику-герою тоже выбивает из седла.

## Враги и боссы
Щитоносец (держит удары в лоб), копейщик (длинный выпад), амазонка-налётчица (быстрая, прыжок-удар),
громила (держит удары, сбивает). Каждый удар врага — с замахом-предупреждением. Волны запирают экран,
после зачистки — «ВПЕРЁД →». Боссы: **Бронный Воевода**, **Близнецы-молотобойцы**, **Ловчий на огнеящере**,
**Цепник-паромщик**, **Стенобой**, **Чёрный Литейщик** (фазы ярости, расплав под ногами, подмога).
Волна по земле — перепрыгнуть или уйти по глубине.

## Жизни и счёт
3 жизни на игрока, полоса здоровья, +1 жизнь каждые 60 000 очков, **2 продолжения** («Продолжить?» с отсчётом),
рекорд (`arcade.best.druzhina`). Награда за этап — по остатку здоровья.

## Управление
| | Игрок 1 | Игрок 2 |
|---|---|---|
| ходьба (вдоль и вглубь) | стрелки | WASD |
| удар | `/` | X |
| прыжок | пробел | Z |
| магия | `.` | C |
| «спина» | `,` | V |

В одиночку работают обе раскладки. 1/2 на заставке — число игроков, Enter — старт, P/Esc — пауза,
L — язык, T — тема, M — звук. Тач (только И1): крестовина, удар, прыжок, магия, «спина», пауза.

## Темы
**modern** (по умолчанию) — мягкие градиенты, тени, сглаженные фигуры; **retro** — своя 23-цветная палитра,
мир рисуется в буфер 320×180 и растягивается ×3 без сглаживания.

## Файлы
`index.html`, `engine.js` (копия `_shared/engine.js`), `css/style.css`, `js/music.js` (оригинальная тема,
`Arcade.tracks.druzhina`), `js/i18n.js`, `js/game.js` (логика без DOM), `js/audio.js` (SFX), `js/modern.js` и
`js/classic.js` (палитры тем), `js/render.js` (фоны, фигуры, звери, эффекты), `js/ui.js` (HUD, экраны, буфер retro),
`js/main.js` (сборка), `tests/engine.test.mjs`, `tests/bot.mjs` («человеческий» бот).

## Тесты
`node druzhina/tests/engine.test.mjs` (`QUICK=1` — без партий бота). Бот: реакция 150–250 мс, видит только кадр,
замах врага замечает не всегда; проверяется проходимость каждого этапа, этап 1 ≥ 90%, вся игра в одиночку
без продолжений 20–50%, кооп ≤ 85%.
