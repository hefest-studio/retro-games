## 3. Остаточные P2 — визуальные (неинтерактивные элементы), требуют решения

Проверено визуально по скриншотам/увеличенным кропам; пересечения с неинтерактивным текстом считались диагностически (rect-пересечение плашки с `h1-h3,p,strong,b,label,img`), затем проверялись глазами.

### P2-1. lost-vikings-2 — перекрыт логотип «LOST VIKINGS II»
- **1440×900:** плашка `left-mid` (0, 435, 91×31) закрывает левый край «V» в слове «VIKINGS» (≈25% площади плашки над H1).
- **844×390 (ландшафт):** плашка `left-mid` (0, 180, 91×31) перекрывает «VI» логотипа (≈68% площади плашки).
- Скрины: `backlink-fix/p2-lv2-logo-1440x900.png`, `p2-lv2-logo-844x390.png`; полные — `desktop-lost-vikings-2-1440x900.png`, `extra-lost-vikings-2-844x390.png`.
- Шаги: открыть `/lost-vikings-2/` на 1440×900 или 844×390 → плашка закрывает часть логотипа.
- Причина: алгоритм проверяет только интерактивные элементы, логотип — `h1.logo`.

### P2-2. lost-vikings-2 — перекрыт заголовок меню «ВЫБЕРИТЕ ПУТЬ»
- 360×640, 375×667, 390×844, 430×932: плашка `left-mid` закрывает начало заголовка, видно только «…ТЕ ПУТЬ» (скрыто «ВЫБЕРИ»); элемент — `p.panel__label` (не интерактивный, поэтому алгоритм оставляет left-mid).
- Скрины: `backlink-fix/p2-lv2-menu-360x640.png`, `p2-lv2-menu-375x667.png`, `p2-lv2-menu-390x844.png`; полный — `mobile-lost-vikings-2-390x844.png`.
- Шаги: открыть `/lost-vikings-2/` при 390×844 → заголовок панели «ВЫБЕРИТЕ ПУТЬ» частично скрыт.

### P2-3. boulder-dash — перекрыт HUD «УРОВЕНЬ 01»
- **430×932:** плашка `left-mid` (0, 453, 79×27) закрывает HUD-ячейку: не видно метки «УРОВЕНЬ», цифра «01» частично скрыта.
- **414×896:** задет край «01» (≈11% площади плашки).
- Скрины: `backlink-fix/p3-bd-hud-430x932.png`, `p3-bd-hud-414x896.png`, полный `boulder-dash-430x932.png`.
- Шаги: открыть `/boulder-dash/` при 430×932 → левая верхняя HUD-ячейка частично под плашкой.

**Идея фикса (автору):** в `interactiveBoxes()` добавить и «важные» неинтерактивные узлы — `h1,h2,h3,strong,b,label,p,[class*=logo],[class*=hud],img` (видимые, ненулевые) — тогда на этих экранах плашка уйдёт в следующий свободный слот (top-left/bottom-right и т.д.). Либо отдельно для логотипа/заголовков, либо считать «занятым» любой видимый текст с площадью больше порога. Я игры не правлю (приёмка).
