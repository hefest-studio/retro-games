# МАЯЧНИЦА · пилот рисованного приключения без слов (point-and-click)

Пилот студии **«Гефест»**, папка `kvest/`. Сейчас он скрыт: его нет в каталоге и в sitemap, на странице стоит `noindex`.
Оформление временное — **серый макет** (`js/themes/grey.js`). Финальный стиль подключается заменой одного файла темы
по контракту «КВЕСТ» (раздел «Как подключить новую тему» ниже). Всё сделано на чистом HTML5/Canvas, оболочка —
Гефест Arcade v2.2 (меню, пауза, язык, звук, музыка), без сборки и без внешних ресурсов.

**Сюжет (без единого слова).** Посёлок фонарщиков на мысу. В шторм погас маяк, наползает туман, и рыбацкие лодки
не могут найти дорогу домой. Старый мастер слёг с простудой и рассказывает об этом мыслями-пиктограммами.
Его подмастерье Тая (коса, длинное пальто, шарф, сумка через плечо) должна собрать для большого фонаря **линзу, фитиль,
масло и огонь** и зажечь маяк. В финале лодки выходят из тумана.

## Механика
- Клик или тап — героиня идёт по полосе ходьбы. Действовать можно только с тем, до чего она дотянулась: к зоне она
  подходит сама, тянется (поза reach), и только после этого срабатывает действие. Высокое без табурета не достать.
- Курсор меняется над зонами (`use / take / go / look`, на пустом месте — `walk`). Долгий тап или правая кнопка —
  осмотр (мысль с пиктограммами).
- Инвентарь — полоса внизу. Предмет можно перетащить на объект или на другой предмет (комбинация), а можно тапнуть
  по нему и затем по цели.
- **Подсказка** (лампочка, H) — мысль-пузырь с намёком на текущую цель. Цель берётся из реестра головоломок.
  В каждой сцене одна подсказка бесплатна, дальше — по таймеру (45 с) или после мини-игры «поймай трёх светлячков».
- **Прохождение-набросок** (книжка, B, или пункт меню паузы) — карточки-шаги без слов, 5 страниц.
- Кат-сцены идут движком: мысли мастера, жесты, проход героини, финал. Тап пропускает кат-сцену.
- Прогресс сохраняется в localStorage (`arcade.save.kvest`, версия 1). В меню: Новая игра / Продолжить · N/26 /
  Язык / Звук. Звуковые эффекты — WebAudio, музыка — тихий эмбиент `Arcade.tracks.kvest`.
- Клавиша D включает отладку макета: подписи объектов, рамки зон, полосу ходьбы.

## Сцены и головоломки (9 сцен, 26 головоломок)
| Сцена | Головоломки | Тип |
|---|---|---|
| 1. Мастерская | табурет под полку → маслёнка; 4 взаимозависимых тумблера → ящик (фитиль, огниво); поленья + огниво → печь; фонарь к огню | механика ×2, предметные ×2 |
| 2. Площадь | ведро → колодец; вода → пекарше (хлеб); хлеб → козе (поленница) | предметные ×3 (+ подсказка-мелодия: птицы на столбиках) |
| 3. Причал | кран: три рычага по порядку → ведро; сеть + «кошка» → рыба; рыба → кошке (ключ); ключ → сарай | механика, предметные ×3 |
| (инвентарь) | верёвка + крюк → «кошка»; мутная линза + тряпица → линза | комбинирование ×2 |
| 4. Лодочный сарай | 3 вентиля и манометр; **мини-игра «трубы»**; маслёнка → носик | механика, мини-игра, предметная |
| 5. Грот | огонь в темноте; «кошка» → ракушка из лужи; **плиты со знаками** (порядок — на табличке в сарае); ракушка → чайке (линза) | предметные ×3, наблюдательная |
| 6. Тропа на мыс | ворот + стопор + 3 оборота лебёдки → мост | механика |
| 7. Подножие маяка | **кодовые диски** (код — на чертеже в мастерской) | наблюдательная |
| 8. Лестница маяка | **мини-игра «колокольчики»**: мелодия = высоты птиц на площади | мини-игра (наблюдательная) |
| 9. Фонарная | **мини-игра «сдвижная оправа» 3×3**; линза, фитиль, масло в фонарь; огонь → маяк | мини-игра, предметные ×2 |

Итого 16 предметных, 5 механических, 3 мини-игры, 2 наблюдательные (у мелодии подсказка тоже в другой сцене).
Число головоломок считается по данным (`KVEST.PUZZLES.puzzles`).

## Файлы
- `js/scenes.js` — сцены в формате контракта плюс поля пилота: `show`, `bind`, `need`, `at`, `look`, `to/toX/toNeed`,
  `icon`, `darkUnless`, `walkIf`.
- `js/puzzles.js` — правила, комбинации, входы в сцены, авто-правила, кат-сцены, механизмы и мини-игры, реестр
  головоломок. Всё это данные, функций там нет.
- `js/widgets.js` — логика механизмов: toggles, gauge, sequence, dials. И мини-игр: pipes, slider, melody, catch.
  Мини-игра отдаёт сцену крупного плана, собранную из kind контракта, и рисует её та же тема.
- `js/game.js` — движок: интерпретатор правил, ходьба, ввод, инвентарь, подсказки, кат-сцены, сохранение.
  Модель для отрисовки — `G.model()`.
- `js/theme-api.js` — словарь kind (контракт + расширения `sign`, `shelf`, `chime`), состояния, которые тема должна
  читать, словарь пиктограмм, раскладка интерфейса, `validateTheme(theme)`.
- `js/themes/grey.js` — временная тема (серый макет). `js/main.js` — оболочка Arcade и DOM.
  `js/audio.js` — эффекты, `js/music.js` — музыка, `js/i18n.js` — RU/EN меню.
- `tests/engine.test.mjs` — тесты; `tests/solver.mjs` — поиск по состояниям; `tests/bot.mjs` — бот-«игрок».

## Как подключить новую тему («бумага» / «тушь»)
1. Скопировать `_proto/style-<имя>/theme.js` в `kvest/js/themes/<имя>.js`. Файл должен объявлять `window.KvestTheme`
   (id, name, 7 методов).
2. В `kvest/index.html` заменить строку `<script src="./js/themes/grey.js">` на новый файл. Порядок скриптов
   не менять: тема грузится после `theme-api.js` и до `main.js`.
3. Открыть `kvest/index.html?check`: в консоли должно появиться `KvestTheme <id>: OK` (это `validateTheme` с настоящей
   канвой). Затем пройти сцены в режиме отладки (D).
4. **Научить тему состояниям пилота** — без этого головоломки читаются плохо. Список — в `theme-api.js`
   (`KINDS`/`EXT_KINDS`). Главное:
   - `npc.state.type`: master, baker, goat, cat, gull, bird (+ `post`, `sing`);
   - `machine.state.variant`: stove, well, crane (`prog`, `load`), tank, gauge (`gauge`, `mark`, `ok`), spout (`drip`), winch, carriage;
   - `box.state.variant`: stool, bench (`open`, `empty`), logs, net, panel; `box.state.icon` — диски кода; `box.state.pic/part/n` — плитки оправы;
   - `pipe.state.shape/rot/wet/fixed` — плитки мини-игры; `lamp.state.big/lens/wick/oil/lit`, `lamp.state.small`;
   - `rock.state.plate/icon/down`, `rock.state.variant: steps (up) | pillar`; `bridge.state.lift`; `door.state.lock/hatch`;
   - расширенные kind: `sign` (`icons`), `shelf`, `chime` (`note`, `n`, `ring`);
   - пиктограммы — все id из `ICONS`, включая `n0…n4`, `dot1…dot3`, `lever_on/off`, `lamp_off`.
   Проверено 14.11: оба прототипа проходят `validateTheme` и рисуют все 9 сцен и мини-игры без ошибок, но поля
   из п. 4 пока игнорируют. Например, все `npc` у них выходят одинаковыми фигурами: птицы на столбиках становятся
   людьми, коза и колодец не различаются.
5. Прогнать `node kvest/tests/engine.test.mjs`. В список `FILES` теста можно добавить новую тему, чтобы её проверял
   и Node; для текстур на пикселях `mockCtx` умеет `createImageData`/`getImageData`/`createPattern`, но `Path2D` и
   `DOMMatrix` в Node нет, поэтому такие темы проверяются в браузере через `?check`.

## Проверка
`node kvest/tests/engine.test.mjs` (с переменной `QUICK=1` — без бота). Что проверяется:
- решаемость главы поиском по состояниям и отсутствие тупиков;
- 20–30 головоломок по данным;
- решаемость каждого механизма и мини-игры, в том числе из любого их состояния;
- сохранение и загрузка;
- `validateTheme(grey)`; все kind взяты из словаря;
- бот проходит главу кликами и перетаскиваниями;
- правило имён: стоп-лист хранится в base64.
