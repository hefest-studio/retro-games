# ТЕТРИС · Каскад

Переосмысление классического тетриса (1984) на чистом HTML5/Canvas. Открывается как
`tetris/index.html` по `file://` — без сборки, CDN, npm и интернета. RU/EN, два режима
графики (**8-бит** и **неон**), оригинальный чиптюн и SFX на WebAudio.

## Как играть
- **← →** — двигать фигуру
- **↑ / X** — поворот по часовой, **Z** — против
- **↓** — мягкий сброс, **Пробел** — жёсткий сброс
- **C / Shift** — отложить фигуру (запас)
- **P** — пауза · **G** — графика · **M** — звук · **L** — язык

Собирай горизонтальные линии — они исчезают и дают очки (100/300/500/**800** за 4 линии,
× уровень). Каждые 10 линий — уровень выше и быстрее. Игра заканчивается, когда стакан
переполнен.

## Что внутри (структура)
| Файл | Назначение |
|---|---|
| `index.html` | каркас: `<canvas>` + топ-бар + оверлеи |
| `css/style.css` | вёрстка, темы (8-бит/неон), адаптив |
| `js/i18n.js` | строки RU/EN (`TT.t`) |
| `js/audio.js` | чиптюн + SFX (WebAudio), `TT.audio` |
| `js/game.js` | **движок, DOM-free, детерминированный** (`TT.Game`) |
| `js/classic.js` | рендерер 8-бит (`TT.classic`) |
| `js/modern.js` | рендерер неон (`TT.modern`) |
| `js/ui.js` | DOM-оверлеи (`TT.ui`) |
| `js/main.js` | boot, rAF-цикл, ввод, настройки, localStorage |
| `tests/engine.test.mjs` | автотесты логики (Node, без зависимостей) |

## Тесты
```bash
node tetris/tests/engine.test.mjs   # 9 проверок логики движка (без браузера)
```
