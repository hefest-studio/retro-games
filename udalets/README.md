# УДАЛЕЦ · Кубки Мастера

Оригинальная игра студии **«Гефест»**: экранный платформер в жанре «найди кубок на уровне → дойди до двери»
(в духе ранних 8-битных платформеров для ПК). Чистый HTML5/Canvas на фреймворке Гефест Arcade v2.2: без сборки,
CDN, шрифтов и ассетов из сети, открывается как `udalets/index.html` (в том числе по `file://`).

Мастерская «Гефест» когда-то держала цеха по всей округе, теперь они заброшены — и в каждом остался
**Кубок Мастера**. За ними отправляется **Удалец** — подмастерье в красном картузе с очками-гоглами,
синей рубахе и кожаном фартуке. Десять цехов: Старый цех, Кузня, Литейная, Кислотные чаны, Трубный ярус,
Башня ветров, Часовой механизм, Котельная, Шпиль и Горн Мастера.

## Правила
- **Уровень** — 2–3 экрана (у Трубного яруса и Шпиля один экран ниже — туда спускаются через пролом в полу).
  Экран сменяется целиком, когда Удалец выходит за край (флип-скрин).
- **Кубок Мастера** (+1000) лежит где-то на уровне; **дверь** выхода открывается, только когда он взят.
  За дверь — +500 и бонус за время (10 очков за каждую секунду быстрее двух минут).
- **Находки:** шестерня 50, самоцвет 150, сапфир 300, рубин 500. Каждые 20 000 очков — лишняя жизнь (до 5).
- **Опасности:** шипы, огонь, кислота — гибель при касании. Обитатели — тоже:
  **шестерняки** (ходят по полу и платформам, не сходят с края), **искрокрылы** (летают по горизонтали, покачиваясь),
  **клёпани** (ходят по отвесу вверх-вниз), с 7-го уровня — **плевуны** (парят и плюются угольками в сторону Удальца,
  если он примерно на их высоте; перед выстрелом их топка вспыхивает).
- **Ружьё** — с 3-го уровня. 8 зарядов, ящики патронов (+5, не больше 20); остаётся между уровнями. Выстрел — по взгляду.
- **Реактивный ранец** — с 6-го уровня, на каждом уровне свой (не переносится). Shift/C — включить/выключить,
  в полёте стрелки ведут во все стороны без гравитации. Топливо (100) тает и при зависании; канистра +60.
  Кончилось — падение. С 6-го уровня без ранца Кубок не достать.
- **Тайники:** часть стен — ложные (проходимы, выглядят как кладка с еле заметной трещиной). За ними — самоцветы,
  лишняя жизнь (6-й уровень) или **вход в Тайную кладовую** (уровни 2, 5, 8): бонус-экран из самоцветов на 25 секунд;
  после двери или по таймеру Удалец возвращается на то же место уровня.
- **3 жизни.** После гибели — возврат к месту, где Удалец впервые встал на этом экране, с 2 секундами неуязвимости
  для обитателей. Если загнал себя в угол (кончилось топливо), в паузе есть «Заново уровень» (−1 жизнь, очки остаются).
- **Рекорд** — `arcade.best.udalets` (движок).

## Управление
| Действие | Клавиатура | Тач |
|---|---|---|
| Ходить | ← → / A D | ◀ ▶ |
| Прыжок | ↑ / W / Пробел / Z | ● (или ▲) |
| Выстрел | X / K / Ctrl / F | ✷ |
| Ранец вкл/выкл | Shift / C / V | ⇡ |
| Полёт на ранце | стрелки / WASD | дпад |
| Пауза | P / Esc | II |
| Язык / тема / звук | L / T / M | меню |

## Темы, язык, звук
- **modern** (по умолчанию): цеха в полумраке, кладка с фаской и бликами, стальные балки с заклёпками,
  своё сочетание цветов у каждого цеха, свечение огня, кислоты, самоцветов и открытой двери, виньетка.
- **retro**: 16-цветная палитра, «пиксели» 3×3, кладка в две краски на чёрном фоне, сканлайны.
- RU/EN (`L`), звук — SFX на WebAudio и оригинальная бодрая тема соль мажор (`js/music.js`, `Arcade.tracks.udalets`).

## Файлы
`index.html`, `engine.js` (копия `_shared/engine.js`), `css/style.css`,
`js/i18n.js`, `js/levels.js` (10 уровней и бонус-экран), `js/game.js` (логика, физика, граф проходимости),
`js/audio.js`, `js/music.js`, `js/render.js` (обе темы, HUD), `js/main.js` (сцены, ввод, DOM);
тесты — `tests/engine.test.mjs`, бот — `tests/bot.mjs`. Контракт модулей — `CONTRACT.md`.

## Проверка
`node udalets/tests/engine.test.mjs` — уровни и прогрессия, физика, опасности, жизни, Кубок/дверь, ружьё, ранец,
тайники и бонус-экран, «Заново уровень», обитатели; **проходимость всех 10 уровней** по графу (Кубок и дверь достижимы,
6–10 — только с ранцем, тупиков нет, 400 рёбер графа воспроизводятся в игре) и прогоном бота без ошибок через каждый уровень;
музыка, i18n, «правило имён» и 40 партий «человеческого» бота (`QUICK=1` — без партий).
