# ГЛУБЬ — контракт модулей

Игра аркады «Гефест» на фреймворке Гефест Arcade v2.2 (`engine.js`). Общий стандарт:
офлайн, `file://`, без внешних URL/шрифтов/ассетов, RU/EN, темы modern/retro (меняют
только отрисовку), WebAudio-звук, рекорд в `localStorage` (`arcade.best.glub`, лучшее время — `arcade.besttime.glub`).
Права: название, герой (водолаз-рудознатец), крот Бурик, кристаллы, обитатели, мир, арт (пиксельный и векторный),
палитры, звуки и музыка — оригинальные; чужих имён и терминов нет (тест «Правило имён»).

## js/game.js — `GLUB.Game(opts)` (без DOM, детерминирована при заданном `rng`)
`opts`: `{ rng, lives=3, world, onEvent(type,data), dmgMul=1 (только тесты) }`.

Экран 20×12 клеток (32 px, HUD 36 px сверху → канва 640×420). Мир 9×8 экранов строится один раз (`logic.world()`).
Клетки: `E` пусто, `R` скала, `SO` мягкая порода (группа `g`, под ней `u` — пусто или лестница), `LD` лестница
(верхняя клетка — опора), `SL` шлак (жжёт, подбрасывает), `GT` Печать, `VT` паровой клапан, `PF` балка (односторонняя).
За краем экрана повторяется крайняя клетка (дверь/лестница/провал «продолжаются» в соседа).

API: `start()` → api · `update(dt)` (шаг 1/60) · `setInput(dx, dy, jump)` (↑ без лестницы рядом = прыжок) ·
`mole(force?)` (Бурик; `force`: −1/1, `'D'`, `'U'`; без него — по взгляду и ↑/↓) · `canClimb()` · `state()` → S.
Тестовые хуки: `_hurt(dmg,x,why)`, `_die(why)`, `_enter(room)`, `_place(room,c,r)`, `_giveCrystals(n)`.

`S`: `phase('play'|'dead'|'won'|'over'), phaseT, time, score, lives, energy (0..100), over, won, room,
hero{room,x,y,vx,vy,ground,climb,face,stun,coy,kb,inv,apex,walkT}, mole{state:'home'|'out'|'dig'|'back',x,y,dir,vert,gid,t},
dug{gid:true}, gate, got{itemId:true}, crystals[cid], visited{room:true}, enemies[{type:'moth'|'crawler',x,y,…,alive}],
cp{room,x,y,id}, deaths, stuns, hurts, kills, finalBonus`.

События `onEvent`: `room{room,zone}`, `jump`, `thud{fall}`, `stun{fall,x,y}`, `hurt{why,energy}`, `slag`, `die{why,lives}`, `respawn`,
`gameover`, `crystal{cid,n,x,y}`, `gateOpen`, `beacon{fresh,first}`, `nugget{pts}`, `tank`, `moleOut{dir}`, `digStart`, `dug{gid}`,
`clank`, `moleHome`, `kill{pts}`, `win{time,score,bonus}`.

Правила:
- **Физика:** бег 5,4 кл/с, прыжок 19,6 кл/с при g = 56 (≈3,4 клетки), обрезка прыжка при отпускании, «койот» 0,08 с,
  лестницы 4,4 кл/с. Хитбокс героя 0,68×1,7. Падение ≥ 6,5 клетки (от высшей точки до приземления, через экраны) — оглушение 1,3 с.
- **Бурик:** вбок — летит 9 кл/с по полосе тела (ряды ног и груди) до 12 клеток, на мягкой породе копает 0,45 с
  и съедает всю группу (общую для обеих сторон двери), дальше летит до скалы/края, возвращается к герою 12 кл/с;
  сносит ржавней (+150). Вниз/вверх — грызёт пробку под ногами / над головой.
- **Урон:** копотник 10, ржавень 9, клапан 14, шлак 15; неуязвимость 1,1 с; энергия 0 → −1 жизнь, через 1,6 с — у маяка.
- **Маяк:** касание — контрольная точка (+200 при первом), энергия до полной (повторно — не чаще раза в 10 с).
- **Кристаллы:** +1000; восемь — `gate = true` (Печать проходима). Сердце — только при открытой Печати:
  победа, бонус `5000 + 1000·жизни + 10·(900 − время)`.

`GLUB.logic`: константы, `MAP`, `CSPOT`, `world()`/`buildWorld()`, `tileAt(st,room,cx,cy)`, `isSolid`, `isStand`,
`heroStep(W,st,H,inp,dt)` (общая физика), `moleScan(st,room,c,r,dir)`, `ACTS` (макро-действия: шаг, прыжки с разным
удержанием, лестница вверх/вниз), `drive`/`finished` (ввод действия и его завершение), `Nav(W)` — граф проходимости:
узлы «стою в клетке», рёбра — симуляция `ACTS` настоящей физикой; `solve()` — что достижимо с учётом крота и Печати.

## Рендеры
`GLUB.modern` / `GLUB.classic`: `{ P, bg(ctx,g), draw(ctx,S,g,{bare,toasts,fade,intro}), hero(...), mole(...), lifeIcon, crystalIcon }`.
Статичный слой экрана кэшируется по (экран, выкопанные группы рядом, Печать). `GLUB.ui`: `hud`, `mapOverlay`, `banner`, `toasts`,
DOM (`init/fit/sync`) — тексты только через `g.t()`.

## main.js
Сцены движка (`useStandardScreens`), титул — стартовый экран шахты + меню; `play` — фикс-шаг 1/60, карта (`Tab`/`C`) ставит игру
на паузу; финальные экраны дополнены временем и лучшим временем. `GLUB.app = { g, game(), map() }` — для автотестов в браузере.

## tests
`engine.test.mjs` — логика, мир, граф, имена; `bot.mjs` — `playGlub(GLUB, seed, opts)`: «человеческий» бот на тех же макро-действиях.
