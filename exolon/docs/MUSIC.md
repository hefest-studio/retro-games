# EXOLON HTML5 — музыка и звук

Движок: `exolon/src/audio.js` → `window.EX_AUDIO`. Контракт API: `exolon/docs/CONTRACT.md §2`.
Всё генерируется кодом на WebAudio, без сэмплов и внешних файлов. Файл читается сверху вниз:

| Блок | Что внутри |
|---|---|
| 0. Константы | lookahead, кроссфейд, уровни громкости, лимиты голосов |
| 1. Теория + данные | нотная нотация, аккорды и **все паттерны треков** |
| 2. Компиляция | строки паттернов → события по шагам (время, длительность, портаменто) |
| 3. Граф WebAudio | master → лимитер → destination, шины music/sfx, фильтр музыки, буфер шума |
| 4. Голоса | pulse (PeriodicWave, duty), triangle-бас, noise-ударные, огибающие, вибрато, глиссандо |
| 5. Секвенсор | lookahead-планирование, кроссфейд треков, пауза по `visibilitychange` |
| 6. SFX | 21 эффект, синтез «на месте» |
| 7. API | `window.EX_AUDIO` |

## 4 канала

Как на NES/ZX: 2 импульсных + треугольник + шум.

| Канал | Синтез | Роль |
|---|---|---|
| `lead` | pulse, duty 0.25 (периодическая волна), вибрато на длинных нотах | мелодия |
| `harm` | pulse, duty 0.125 | гармония/арпеджио |
| `bass` | triangle | бас |
| `drums` | сгенерированный буфер шума + фильтры/огибающие | kick/snare/hat/tom/crash |

* **Duty-контроль** — `pulseWave(duty)` строит `PeriodicWave` из ряда Фурье; значения скважности задаются
  в данных канала (`duty: 0.25` / `0.125`), отдельные эффекты используют 0.5.
* **Огибающие без щелчков**: attack 2–8 мс, hold, release 20–80 мс; осциллятор останавливается
  только после линейного спада в 0. У ударных — плавный экспоненциальный спад.
* **Вибрато** — LFO → `osc.detune`, глубина в центах, с задержкой и плавным входом.
* **Портаменто** (`>A4`) — слайд из высоты предыдущей ноты канала (с учётом перехода через начало лупа).
* **Глиссандо** (`A4>C5`) — непрерывный слайд к целевой высоте за длительность ноты.

## Секвенсор

* `setInterval` 25 мс, горизонт планирования `SCHEDULE_AHEAD = 0.12` с; все моменты считаются от
  `AudioContext.currentTime` (sample-accurate, без `setTimeout` на ноты).
* Шаг = 1/16 (4 шага на долю), длина шага = `60 / bpm / 4`.
* Луп бесшовный: шаги просто продолжаются по кругу без сброса времени и без паузы.
* Смена трека — кроссфейд `CROSSFADE = 0.4` с; тот же id повторно не перезапускается.
* Джнглы (`clear`, `gameover`, `win`) имеют `loop: false`: доигрывают один раз, хвост затухает,
  затем трек сам останавливается.
* `setMusic(false)` — музыка мгновенно замолкает, но трек продолжает «идти» и помнит состояние:
  `setMusic(true)` возвращает звук с того же места. `setSfx(false)` глушит только эффекты.
* `duck(true)` — плавно до 25 % громкости музыки (пауза), `duck(false)` — обратно.
* `setIntensity(0..1)` — слой напряжения для `game`: яркость low-pass фильтра музыки,
  дополнительные призрачные хэты, при > 0.7 гармония уходит на октаву вверх.
* Громкость: музыка тише SFX (шина музыки 0.32 против 1.0), на мастере мягкий лимитер
  (`DynamicsCompressor`), чтобы залпы эффектов не клиппили.
* Голоса: не более 24 одновременно и не более 6 на один SFX id.
* `visibilitychange`/`pagehide` — планировщик останавливается, контекст suspend; при возврате
  во вкладку музыка продолжается с текущего места.
* `init()/unlock()` ленивые и идемпотентные; первый жест пользователя сам будит контекст.
  Любой вызов API до `init()` безопасен (тихий no-op), при `suspended` контексте — тоже.

## Нотация паттернов (блок `[MUSIC-DATA-BEGIN]`)

Паттерн — строка на один такт 4/4 = **16 шагов** (шаг — 1/16). Токены разделяются пробелами.

| Токен | Значение |
|---|---|
| `A4`, `C#5`, `Bb3` | нота (буква + необязательный `#`/`b` + октава) |
| `.` | пауза |
| `-` | продлить предыдущую ноту на шаг |
| вертикальная черта | визуальный разделитель такта, на музыку не влияет |
| `!A4` | акцент (громче) |
| `A4~` | вибрато на ноте |
| `>A4` | портаменто из предыдущей высоты канала |
| `A4>C5` | глиссандо A4 → C5 за длительность ноты |
| `K`/`k` | kick (сильный/тихий) |
| `S`/`s` | snare |
| `H`/`h` | closed hat (сильный/тихий) |
| `O` | open hat |
| `C` | crash |
| `T` | tom |

Порядок тактов задаётся массивом `order` (имена паттернов могут повторяться). Все каналы одного
трека обязаны иметь одинаковую суммарную длину, кратную 16. Аккордовая карта трека описана в
`exolon/tools/validate-music.mjs` и проверяется автоматически.

## Треки

Все мелодии оригинальные. Общая гармония — мажор/минор 80-х с арпеджио по аккордовым тонам.

### `title` — титульный экран

* **132 BPM, ля минор, 16 тактов, 29.1 с**, луп.
* Аккорды по тактам: `Am F G Am | Am Am F G | Am Am F E7 | Am F G E7`.
* 1–4 — таинственно-героическое вступление: восходящие арпеджио 16-ми у мелодии
  (Am → F → G → Am), глиссандо `C5>A4` в конце фразы, гармония молчит, бас — педаль с подъёмом,
  барабаны — редкие хэты/томы.
* 5–12 — героическая тема: длинные ноты, ответные фразы, портаменто `>A5` и вибрато `A5~`;
  арпеджио гармонии, бас четвертями, полная ритм-секция, филл на 8-м такте.
* 13–16 — вариация с цитатой боевого мотива и подъёмом, на стыке `E7 → Am` луп замыкается.

### `game` — основной боевой трек

* **150 BPM, ля минор** (натуральный, с дорийским оттенком: `G#` в E7), **32 такта, 51.2 с**, луп.
* Аккорды: A-секция `Am Am F G Am Am F E7`; B-секция `Dm Dm Am Am F G E7 E7`;
  C-секция `F G Am Am F G E7 Am`.
* Форма: **A (1–8)** — цепляющий хук «вопрос-ответ»; **B (9–16)** — ответная фраза в Dm
  (вход портаменто `>D5`); **A' (17–24)** — повтор хука с лёгкой вариацией (gL19, gL24);
  **C (25–32)** — гимновая кульминация, портаменто `>F5`, глиссандо `B4>G#5` и вибрато в конце,
  возврат в Am на стыке.
* Бас — остинато восьмыми (прима/октава), филлы-подъёмы на 8/16/24 тактах и разрешение на 32-м.
* Гармония — 16-е арпеджио по аккордовым тонам; барабаны — 4 рисунка + филлы.
* `setIntensity` добавляет плотность/яркость, не меняя мелодию.

### `exo` — с экзоскелетом

* **156 BPM, тот же материал:** мелодия и бас из `game` без изменений, гармония транспонирована
  на октаву вверх (высокое арпеджио), барабаны плотнее (16-е хэты, open hat, томы),
  темп чуть быстрее. **32 такта, 49.2 с.**

### `final` — финальный сектор

* **160 BPM, ре минор, 24 такта, 36.0 с.**
* Тот же тематический материал `game`, но: мелодия и гармония **−7 полутонов** (A-moll → D-moll),
  бас **+5 полутонов** (те же ступени, но удобный диапазон: D2–D3), барабаны плотнее (как `exo`),
  порядок секций **A → B → C**.
* Аккорды после транспонирования: `Dm Dm Bb C ... Gm ... A7 ... Dm` — финал темнее, с напряжением
  доминанты A7; на стыке лупа `Dm → Dm`.

### `clear` — победа (джингл)

* **160 BPM, до мажор, 2 такта, 3.0 с**, `loop: false`.
* Восходящая фраза `C5 E5 G5 C6` на аккорде C, арпеджио и бас C/G. Доигрывает и замолкает.

### `gameover` — проигрыш (джингл)

* **165 BPM, ре минор, 2 такта, 2.9 с**, `loop: false`.
* Нисходящее арпеджио D5–C5–A4–F4–D4–A3 и разрешение в Dm; низкие педали и редкие барабаны.

### `win` — финальный триумф (джингл)

* **140 BPM, до мажор, 4 такта, 6.9 с**, `loop: false`.
* Фанфарная мелодия `C–F–G–C`, арпеджио, бас и барабаны с том-филлом в конце.

## SFX (21 шт.)

Вызов: `EX_AUDIO.sfx(id)` (до `init()` — тихий no-op; при `setSfx(false)` не играет).

| id | Звук |
|---|---|
| `laser` | короткий писк-разряд, pulse 0.5, 1850→250 Гц |
| `grenade` | пуск: низкий свист + шумовой «пф» |
| `explosion` | шумовой бум 0.42 с, lowpass 1600→90 + суба |
| `bigexpl` | большой бум 0.8 с, два шумовых слоя + саб |
| `hit` | сухой щелчок + короткий блин 240→120 Гц |
| `death` | нисходящий пилообразный вой 640→90 Гц |
| `pickup` | две звонкие ноты вверх (C6→G6) |
| `powerup` | быстрое арпеджио C5 E5 G5 C6 |
| `teleport` | свип 180→2400 Гц с шипением |
| `jump` | короткий подъём 240→740 Гц |
| `land` | низкий глухой удар + саб |
| `exo` | механические тики: пила 180→150 Гц + шумовые щелчки |
| `menu` | одиночный импульс 990 Гц |
| `select` | двухтоновый 660→990 Гц |
| `deny` | низкое «бз-з» 170→130 + 150 Гц |
| `alarm` | два бипа 950/700 Гц |
| `missile` | свист с вибрато + шумовой подсвист |
| `crusher` | низкий рокот + саб 70→38 Гц |
| `clear` | восходящее арпеджио C-мажор, ~0.5 с |
| `gameover` | нисходящее A-G-F-E-D, ~0.8 с |
| `win` | фанфара C-мажор, ~1.1 с |

## Где менять музыку

Всё — в блоке `[MUSIC-DATA-BEGIN]` … `[MUSIC-DATA-END]` в `exolon/src/audio.js`:

* `GAME_LEAD`, `GAME_HARM`, `GAME_BASS`, `GAME_DRUMS` — основной трек;
* `EXO_HARM`, `EXO_DRUMS` — надстройка для экзоскелета;
* `FINAL_BARS`, `FINAL_DRUMS` — финальный сектор (транспонирование и порядок тактов);
* `TITLE_LEAD`, `TITLE_HARM`, `TITLE_BASS`, `TITLE_DRUMS` — титульный экран;
* `TRACKS.clear / gameover / win` — джинглы;
* `DRUMS_BASIC` — общие барабанные рисунки.

BPM и признак лупа — в `TRACKS`. Громкость канала — `gain` в объекте канала.
Тембры/огибающие ударных — `DRUM_KIT` (блок 4), общие уровни — константы в блоке 0.

## Проверка

```bash
node --check exolon/src/audio.js
node exolon/tools/validate-music.mjs            # структура, длины, гармония, SFX/API, без внешних зависимостей
node exolon/tools/probe.mjs exolon/tmp/audio-proof.html exolon/reports/audio-proof.png \
     --w=1000 --h=700 --wait=1500 --eval='JSON.stringify({ready:EX_AUDIO.ready()})'
```

* `validate-music.mjs` исполняет блок данных прямо в Node и проверяет: кратность такту, длины каналов,
  длительности лупов (16–32 такта) и джинглов (2–3 с / 6–8 с), попадание баса и арпеджио в аккорд,
  отсутствие малых секунд/больших септим между одновременными голосами, диапазон нот,
  наличие всех 21 SFX и методов API.
* `audio-proof.html` — страница со всеми треками/эффектами, живым статусом
  (`ready()`, `AudioContext.state`, счётчик запланированных нот, голоса, трек/шаг).
  `audio-safety.html` — проверка вызовов до `init()`.

## Отклонение от буквы контракта

В `CONTRACT.md §2` одновременно указаны boolean-геттеры `music, sfx` и метод `sfx(id)` — на одном
объекте это невозможно. Согласовано с Lead: `EX_AUDIO.sfx(id)` — метод, `EX_AUDIO.music` — boolean-геттер,
состояние эффектов доступно как `EX_AUDIO.sfxOn`. Игра читает настройки из `EX.settings` и вызывает
только `sfx(id)`, поэтому конфликта нет.
