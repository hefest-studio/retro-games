# EXOLON HTML5 — данные уровней (`exolon/src/levels.js`)

Оригинал: **125 экранов = 5 уровней по 25**. В порте — **5 уровней по 5 экранов**
(25 экранов), механика и дух сохранены: флип-скрин, экзоскелет в середине уровня,
телепорты, бонусные «пушки-статуи», финальный выбор очков.

```js
window.EX_LEVELS = [
  {
    id: 0,
    name:  {ru: 'ВНЕШНИЙ ПЕРИМЕТР', en: 'OUTER PERIMETER'},   // ЗАГЛАВНЫМИ, до 18 симв.
    theme: 'space' | 'cavern' | 'reactor' | 'hive' | 'core',   // палитра/фон
    intro: {ru: '...', en: '...'},   // 1–2 короткие строки брифинга
    screens: [ screen, screen, screen, screen, screen ]
  },
  ...
];
```

## Экран

```js
{
  tiles: [ '...32 символа...', 24 строки ],   // ровно 24 строки по 32 символа
  entities: [ {t:'walker', x:12, y:19, dir:-1}, ... ],
  spawn: {x:2, y:21},      // необязательно; по умолчанию игрок появляется слева
  name: {ru:'...', en:'...'}  // необязательная подпись экрана  (для режима MODERN)
}
```

* Координаты `x,y` — **в тайлах**, `x` в `0..31`, `y` в `0..23`, `y = 0` — верхняя строка.
* `y` у сущности — тайл, на **нижнюю границу которого** опирается сущность
  (низ сущности = `(y+1)*8`); для летающих — та же логика («низ» спрайта).
* Игрок всегда стартует на левом краю экрана; цель — **уйти за правый край**
  (`x > 248` + касание земли). Правый край держите проходимым.
* Ширина игрока 10 px (exo 14 px), высота 16 px (exo 18 px).
  Прыжок: высота ~3.5 тайла, дальность ~5 тайлов. Проходы делайте ≥3 тайлов
  высотой, уступы — не выше 3 тайлов.
* Экран должен быть **проходим слева направо** без обязательного использования
  телепорта/разрушения (разрушаемые блоки — как секретный путь).

## Тайлы (по одному символу)

| Символ | Значение | Свойства |
|---|---|---|
| ` ` | пусто | — |
| `#` | твёрдый блок (порода/металл) | неразрушим, опора |
| `=` | тонкая платформа (решетка) | опора сверху, проходима снизу/сквозь при прыжке |
| `%` | разрушаемый камень | опора; **граната** уничтожает 3×3 тайла вокруг |
| `^` | шипы | смертельно; опора отсутствует |
| `x` | декоративная флора (куст/гриб) | не мешает, не опора |

Фон рисуется рендерером (звёзды/пещеры/реактор) — тайлами не задаётся.

## Сущности

| `t` | Размер (px) | Поведение | Очки | Убивается |
|---|---|---|---|---|
| `walker` | 14×12 | патрулирует по земле в радиусе `range` тайлов (по умолч. 4), разворачивается на краю/стене | 150 | бластер (1) |
| `flyer` | 16×12 | синусоида вверх-вниз, летит в сторону игрока, разворот у края | 150 | бластер (1) |
| `swarmer` | 8×8 | маленький рой, медленно летит к игроку | 50 | бластер (1) |
| `turret` | 12×10 | неподвижная пушка, стреляет горизонтально в сторону игрока каждые 2 с | 150 | **только граната** |
| `tank` | 16×12 | едет по земле к игроку, стреляет снарядами | 200 | только граната (2) |
| `mine` | 8×6 | мина на земле; игрок ближе 20 px → взрыв через 0.3 с | 50 | бластер/граната |
| `crusher` | 16×16 | пневматический молот у потолка: удар вниз на 2 тайла раз в ~1.6 с, отбрасывает игрока | — | неубиваем |
| `pod` | 14×12 | «родильный» кокон: каждые 2.5 с выпускает `swarmer` (макс. 3) | 150 | **только граната** |
| `homer` | 14×12 | модуль наведения: каждые 3 с запускает самонаводящуюся ракету | 1000 | бластер (3)/граната |
| `double_launcher` | 12×16 | статуя-бонус: войти в неё | 2000 | «собирается» касанием |
| `combo_launcher` | 14×16 | статуя-бонус: войти в неё | 3000 | «собирается» касанием |
| `power_laser` | 8×8 | синий патрон: +30 заряда бластера | — | подбирается |
| `power_rocket` | 8×8 | малиновый патрон: +3 гранаты | — | подбирается |
| `exo` | 16×20 | капсула экзоскелета (1 на уровень, на 3-м экране) | — | вход → exo до конца уровня |
| `teleporter` | 12×16 | пара телепортов на экране; `↓` на платформе → к парному | — | — |

Телепорты задаются двумя сущностями с одинаковым `group` (1..3):

```js
{t:'teleporter', x:3, y:19, group:1},
{t:'teleporter', x:27, y:7, group:1}
```

Прочие необязательные поля: `dir` (-1/1, стартовое направление),
`range` (тайлы патрулирования), `phase` (0..1, сдвиг синуса/таймера),
`flip` (true — зеркальный спрайт).

## Требования к контенту

1. **Ровно 5 уровней × 5 экранов.** Плотность растёт: ур. 1 — 3–6 врагов на экран,
   ур. 5 — 7–12 + комбинации ловушек.
2. На каждом экране: опора под ногами, чистый спавн слева (первые 2 тайла), выход
   справа. Ловушки не должны быть дешёвыми (мина прямо на спавне — нет).
3. `exo` — один на уровень, на `screens[2]`.
4. `power_laser`/`power_rocket` — 1–2 на уровень, в достижимых местах (можно на
   платформе сверху).
5. `teleporter` — на 1–2 экранах каждого уровня, парами, ведут в укромное место
   с наградой.
6. `double_launcher`/`combo_launcher` — 1–2 на уровень, в тупичках/на верхотуре.
7. Платформы `=` не должны образовывать «мясорубку»; комбинация `crusher` + узкий
   проход — только на 4–5 уровне.
8. Визуально разнообразьте: разные высоты этажей, шахты, «балконы», карманы.
   Ориентир — карта оригинала `exolon/docs/reference/exolon-map.png`
   (пять горизонтальных полос = 5 уровней, открывается любым просмотрщиком).

## Валидатор

```bash
node exolon/tools/validate-levels.mjs
```

Проверяет: структуру, размеры, спавн/выход, сущности внутри твёрдых тайлов,
пары телепортов, достижимость выхода упрощённым BFS (прыжок 3 тайла вверх,
5 в длину, падение вниз) и печатает статистику по сложности.
