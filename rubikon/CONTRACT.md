# РУБИКОН — HTML5: стандарт игры аркады «Гефест»

Оригинальная игра студии **«Гефест»** — «Робот ОР-КАБЕ» (жанр: Аркада).
Открывается как `rubikon/index.html` по `file://` — **без сборки, CDN, npm и интернета**.
Весь контент рисуется/синтезируется кодом: нет внешних картинок, шрифтов и аудиофайлов.

> Этот файл фиксирует общий стандарт аркады и специфику игры. Детальные контракты модулей
> (как в `krot/CONTRACT.md`) дописываются при рефакторинге конкретной игры.

## Что это
Оригинальная аркада студии «Гефест»: проведи робота ОР-КАБЕ сквозь уровни к поверхности, уклоняясь от врагов. Стиль CGA и неоновый ремастер, RU/EN.

- **Управление:** Стрелки / WASD, пробел — лазер, Shift — отделить башню
- **Языки:** RU / EN
- **Акцентный цвет:** `#ff4fd8`

## Возможности
- 10 подземных уровней + поверхность
- Две графики: CGA и NEON
- Отделяемая летающая башня
- Броня, энергия и перегрев лазера

## Общий стандарт аркады «Гефест» (инвариант для всех игр)
- Полностью **офлайн**, открывается по `file://`, без сборки/CDN/npm/сети и внешних ассетов.
- Два режима графики: **ретро (8-бит)** и **модерн (неон)**; переключение клавишей `G`.
- Локализация **RU/EN**; строки — через слой i18n, без хардкода в рендерере.
- Звук и музыка — **только WebAudio** (чиптюн + SFX), оригинальные мелодии (не копии).
- Один `<canvas>`; рендерер закрашивает всю площадь каждый кадр; ввод по `e.code` (работает кириллица).
- Рекорд и настройки — в `localStorage`; графика при старте принудительно ретро.
- Код: `'use strict'`, без `import/export`/`fetch`/внешних URL; комментарии по-русски.
- **Авторские права:** названия, спрайты, музыка и палитры — оригинальные; оригинальные ассеты чужих игр не используются.

## Definition of Done
- `rubikon/index.html` открывается по `file://` в Chrome/Safari/Firefox: титул → игра → пауза → game over → рестарт; обе графики, оба языка, звук/музыка, мобильный layout.
- В консоли нет ошибок; всё работает офлайн, внешних ассетов нет.
- Проходит смоук-тест репозитория: `node tools/smoke.mjs` (парс всего JS + наличие `<canvas>`).
