# КАЛЁНЫЙ ДВОР · Вышибалы в мастерских (EN: CINDER COURT)

Оригинальная игра студии **«Гефест»**, сделанная сразу под телефон, геймпад и площадки (Яндекс Игры, GamePush): вышибалы 3 на 3
во дворах мастерских. Чистый HTML5/Canvas на фреймворке Гефест Arcade v2 (движок v2.10): без сборки, CDN и ассетов из сети,
открывается как `kaleny/index.html` (в том числе по `file://`).

**Название.** RU — КАЛЁНЫЙ ДВОР, EN/TR/ES/PT — CINDER COURT (одно имя внутри языка, Яндекс 5.1.3). Рабочее «ГОРЯЧИЙ ШАР» не взято как слишком
общее; поиск 26.11.2026 игр «Cinder Court» (dodgeball) и «Калёный двор» (вышибалы) совпадений не дал. TR/ES/PT — перевод ИИ, носитель не вычитывал.

## Механика
- **Две половины поля, 3 на 3, два шара.** Каждый подмастерье — 2 «здоровья» (кольцо в HUD). Шар ранит (−1) или выбивает; выбитый уходит
  **за линию соперника** и бросает оттуда (шар, залетевший в его зону, подхватывается сам; ИИ-выбитые бросают сами). Матч — до полного выбивания
  или 100 с: больше выживших, затем больше здоровья; ничья → «до первого попадания» (45 с) → переигровка.
- **Накал (heat 0…1).** Шар раскаляется в полёте (+0,28/с) от тёмного железа к белому: цвет, свечение и хвост — по накалу. Бросок: **тап — холодный** (накал 0,25),
  **удержание — накал** до 0,95 за 1,1 с (кольцо вокруг героя; > 1,7 с — **ожог**: шар падает, герой оглушён 0,9 с). Скорость шара 250…565 px/с по накалу.
- **Ловля в накал — «визитка».** B при угрозе открывает «клещи» на время `0,52 − 0,34·heat` с (холодный — 0,52, белый — 0,18) и откат 0,45 с. Шар попал в окно — пойман:
  бросавший выбывает (если шар ≥ 0,35); **«закалка»** (шар ≥ 0,7) ещё и возвращает в строй своего выбывшего. Рано/поздно/в откате — попадание.
  Подсказка у героя: кольцо сжимается к пунктирной метке — жми, когда оно коснулось (метка ближе у горячего шара).
- **B без угрозы — рывок** (0,2 с неуязвимости, откат 1 с). **Пас:** стик в сторону напарника (в конусе ±40° — цель выбирается автоприцелом; врагов и своих).
- **Паровые щиты (арены 2–7):** `plate` — железная плита (отражает шар, не пускает игроков); `steam` — завеса, пульсирует (период 3,6–5 с; за 0,6 с — мигание):
  гасит и остужает шар. 7 дворов: Кузнечный, Литейный (плиты), Паровой (завесы), Слесарный, Котельный, Двора Наковальни, Большой.
- **Турнир** — 7 матчей, соперник и двор растут (`LEVELS`: скорость 108→138, пауза броска 1,7→1,0 с, разброс прицела 0,30→0,17 рад, шанс ловли 8→40 %…),
  **2 попытки** на переигровку проигранного матча. Очки победы: `(200 + 60·живых + 3·секунд + 50·закалок + 10·выбитых) · (1 + 0,1·номер матча)`.
  **Быстрый матч** — серия побед (уровень растёт 1→6), рекорд серии в `arcade.kaleny.streak`.
- **Кооп 2 игрока** на одном экране (клавиатура/геймпады, `g.usePlayers`): И1 — левый, И2 — правый подмастерье; средний — ИИ-напарник. Один игрок — средний.
- **Облик:** подмастерья — стройные, в фартуках, кепках и защитных очках, сверху; команда игрока — медно-оранжевая, соперники — свой цвет двора (бирюза, сирень,
  зелень, синий, розовый, золото, кость). Не «коренастые хулиганы», без драк, без турне — только дворы мастерских Гефеста.

## Управление
| Действие | Телефон | Клавиатура (И1 / И2) | Геймпад |
|---|---|---|---|
| Бег | плавающий стик слева | стрелки / WASD | стик, крестовина |
| Бросок / пас (держи — накал) | ● | Пробел, Z, `/` / F | A |
| Ловля (при угрозе) / рывок | ◆ | X, C, `.` / G | B |
| Пауза / тема / язык / звук | II / меню | P, Esc / T / L / M | Start |
Автоприцел: стик нейтрален — ближайший соперник; стик в сторону — цель в конусе (враг → бросок, свой → пас).

## Ориентации (16:9 и портрет)
Холст выбирает ориентацию по окну (`js/ui.js`): окно шире высоты ×1,15 → **альбомный 800×450** (поле повёрнуто матрицей: своя команда слева, враг справа; HUD по краям),
иначе **портретный 450×800** (телефон; пульт под полем). Логика всегда портретная (450×800), рендер поворачивает. Стик/клавиши переводятся в мировые оси
(в альбоме «вперёд» = вправо). Сборка `--aspect 16:9` (порталы) работает без правок.

## Площадки (сразу)
- **Языки** RU/EN/TR/ES/PT (`js/i18n.js`), `menuFit` в меню заставки, подгонка холста под окно без прокрутки (телефон портрет/«лёжа», планшет).
- **Реклама:** межстраничная — `g.adBreak()` по нажатию на карточке между матчами (после победы); «ещё матч» — `g.useRewardedContinue` (после проигранного турнира —
  переиграть матч, раз за турнир); бонус в паузе `g.useRewardedBonus` — «подмастерье в строй» (раз за турнир). Рекламы по таймеру и на старте нет.
- **«Без рекламы»** `g.useNoAds({ scene: ['title','pause'] })`; **лидерборд** `kaleny` — очки турнира (шлётся при победе в турнире и при проигрыше), `g.onCloud` досылает рекорд;
  `g.persist` — рекорд, серия, флаг обучения; «Наши игры», ярлык, оценка после успеха. Список для Консоли — `arcade-full/promo/kaleny/platform.json`.
- **Геймпад** — движком (раскладка usePlayers), вибрация при попадании. Тач — `Arcade.touchOk`, стик `js/stick.js` (общая копия).

## Файлы
- `index.html` — страница, канва, пульт (стик + ● + ◆ + II), ссылка «← Каталог». `engine.js` — копия `_shared/engine.js` (кладёт `build.sh`).
- `js/game.js` — логика без DOM (`KALENY.Game`, `KALENY.logic`): юниты, шары, накал, ловля, щиты, ИИ, очки. `js/render.js` — обе темы, поворот поля, HUD.
- `js/main.js` — сцены движка, карточка между матчами, титул с матчем ИИ, ввод, площадка. `js/ui.js` — ориентация и подгонка. `js/audio.js`, `js/music.js`, `js/i18n.js`, `js/stick.js`.
- `tests/engine.test.mjs`, `tests/bot.mjs`. `CONTRACT.md`. Промо — `arcade-full/promo/kaleny/` (`promo.json`, `platform.json`, `shots.mjs`, `art.js`).
- Запись для каталога (`assets/catalog/games.json`) добавляет координатор: `/home/claude/g-kaleny.json`.
