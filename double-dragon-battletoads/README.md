# DOUBLE DRAGON × BATTLE TOADS: NEON RAGE

Фанатский браузерный beat'em-up-кроссовер: **Дракон Кай** и **жаба Рок** выбивают
украденный чип `NEON-8` из лап корпорации «ТОКСИК». 1987 год, неоновый город,
три квартала, пять волн и Тёмная Королева на крыше башни.

Один автономный `index.html`: без сборки, сервера, CDN и внешних файлов.
Вся графика рисуется кодом на Canvas 2D, вся музыка и звуки синтезируются WebAudio.
Работает офлайн, в том числе по `file://`.

## Что это

* Неофициальный фанатский трибьют кроссоверу **Double Dragon × Battletoads** (1993).
* Оригинальные персонажи, спрайты, анимации, музыка и шрифт — **не копии** ассетов
  из игр 1993 года; ничего не скачивается и не загружается извне.
* Игра на один забег: 3 зоны, 5 волн, финальный босс с двумя фазами и телепортом.
* Два визуальных стиля и два языка, переключаются на лету.

## Возможности

* **Русский и английский** интерфейс, по умолчанию русский; тексты адаптированы,
  а не переведены построчно. Переключение — `T`.
* **Две графики**: `8-БИТ` — пиксельный аркадный рендер с CRT-полосами и дизерингом;
  `НЕОН` — гладкий ремастер с градиентами, свечением, дождём и отражениями. `G`.
* **Оригинальная музыка** двух стилей: сухой чиптюн `8-БИТ` и синтвейв `СИНТВЕЙВ`,
  плюс синтезированные звуки ударов, подборов и побед. `M` — вкл/выкл музыку.
* **Боевая система**: серии ударов, пинки, атаки в прыжке, комбо-множитель,
  шкала ярости и спецприёмы. У Кая — «Огненное кольцо», у Рока — «Земляной слэм».
* **Три зоны**: Неоновый проспект → Аркадный переулок → крыша «ТОКСИК».
  Гопники, ниндзя, бугаи; ящики и автоматы с едой и монетами.
* **Финальный босс** — Тёмная Королева: плеть, веер энергошаров, призыв ниндзя
  на второй фазе.
* **Сложность** `ЛЕГКО / НОРМА / ХАРД` влияет на HP, урон и скорость врагов,
  а также на множитель очков.
* **Рекорд** сохраняется в `localStorage` (`dd-neon-settings-v1`) вместе с языком,
  графикой, звуком, CRT и сложностью.
* **Клавиатура, мышь и тач**: меню кликаются, на тач-устройствах появляются
  полупрозрачные неоновые кнопки (крестовина + четыре действия).
* Полноэкранный адаптивный холст, safe-area для iPhone, `reduced-motion` уважается.

## Запуск

1. Откройте `double-dragon-battletoads/index.html` двойным щелчком в браузере.
2. Ничего устанавливать и собирать не нужно — это один самодостаточный HTML-файл.
3. Первое нажатие клавиши или клик включает звук (правило автоплея браузеров).

Нужен современный браузер с Canvas 2D и WebAudio (Chrome, Edge, Firefox, Safari).

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` `↑` `↓` / `WASD` | движение по арене |
| `SPACE` | прыжок |
| `J` / `Z` | удар, серия из трёх |
| `K` / `X` | пинок, тяжёлый |
| `L` / `V` | спецприём при полной шкале ярости |
| `ENTER` | подтвердить / старт / продолжить |
| `ESC` / `P` | пауза, назад, пропустить сюжет |
| `G` | графика: `8-БИТ` ↔ `НЕОН` |
| `T` | язык: `РУ` ↔ `EN` |
| `M` | музыка вкл/выкл |
| `F` | полный экран |

В меню работают стрелки/WASD, `ENTER`, `ESC`, мышь и тап. На телефоне — экранные
кнопки: крестовина слева, удар/пинок/прыжок/ярость справа.

## Настройки

`ESC` → «Настройки» или пункт меню «НАСТРОЙКИ»:

| Строка | Значения |
|---|---|
| Язык | `RU` / `EN` |
| Графика | `8-БИТ` / `НЕОН` |
| Музыка | `ВКЛ` / `ВЫКЛ` |
| Стиль музыки | `8-БИТ` (чиптюн) / `СИНТВЕЙВ` |
| Звуки | `ВКЛ` / `ВЫКЛ` |
| Громкость | 0–100 % |
| CRT-фильтр | `ВКЛ` / `ВЫКЛ` |
| Сложность | `ЛЕГКО` / `НОРМА` / `ХАРД` |
| Сброс рекорда | обнуляет лучший счёт |

Быстрые чипы в правом верхнем углу меню дублируют `G`, `T`, `M`, `F`.
Из паузы настройки возвращают в паузу, из титула — в титул.

## Технические заметки

* Логическая сцена — **480×270** (16:9), масштабируется под окно; рендеры рисуют
  в этих координатах, оболочка добавляет CRT/зерно.
* Canvas 2D, WebAudio, ES2019; каждый модуль — IIFE без `import/export`,
  без внешних библиотек, шрифтов и картинок.
* Исходники лежат в `src/`, итоговый файл собирается скриптом
  `node double-dragon-battletoads/tools/build.mjs` → `index.html`
  (для игрока сборка не требуется).
* Контракт модулей и канонические ключи локализации — `docs/CONTRACT.md`;
  проверка словарей — `node double-dragon-battletoads/tmp/check-i18n.mjs`.

## Структура

```
double-dragon-battletoads/
├── index.html          один автономный файл (открыть в браузере)
├── src/                font, i18n, audio, game, render-retro, render-modern, main, style

```
