# LOST VIKINGS 2 · NORSE BY NORSEWEST — контракт модулей

Фанатский браузерный ремейк **The Lost Vikings 2 / Norse by Norsewest** (1997).
Папка `lost-vikings-2/`. Открывается как `index.html` по `file://` — без сборки, npm,
CDN, интернета, внешних картинок, шрифтов и аудиофайлов. **Всё рисуется и звучит кодом.**

- Язык интерфейса: **русский по умолчанию**, переключатель RU/EN.
- Два режима графики, переключаются на лету: **AURORA** (современный) и **8-BIT** (ретро).
- 6 уровней-головоломок, три викинга со способностями из сиквела, оригинальный чиптюн.
- Дизайн-концепция: **«СЕВЕРНОЕ СИЯНИЕ / NORDIC AURORA»** — полярная ночь, аврора,
  неоновые руны, стекло и хром. Ретро-режим — «Sega Saturn, 1997»: пиксели, дизеринг, CRT.

---

## 0. Жёсткие правила

1. Только **ES2019**, классические скрипты. Никаких `import/export`, `type="module"`,
   top-level await, `?.`, `??`. Всё обязано работать с диска (`file://`).
2. Каждый файл — IIFE, `'use strict'` внутри, пишет в глобал **только свой** неймспейс.
3. Никаких сетевых запросов, `fetch`, XHR, внешних шрифтов/картинок/звуков, npm-зависимостей.
4. Не редактировать чужие файлы. Не коммитить. Временное — в `tmp/<agent>/`.
5. UTF-8, LF, отступ 2 пробела. Комментарии — по-русски, коротко.
6. Модуль не трогает DOM на этапе загрузки (кроме `main.js`). API вызывается из `main.js`.
7. Всё обязано быть отказоустойчивым: вызовы API до `init/unlock` не должны бросать исключений.

## 1. Геометрия мира и физика (единая база для всех)

- Виртуальный экран **1024 × 576** (16:9). Клетка **TILE = 32 px**.
  Видимая область — ровно **32 × 18 клеток**, камера скроллится по уровню.
- Уровень: `cols` 48–80, `rows` 18–30. Мир `cols*32 × rows*32`.
- Координаты мира: `x` вправо, `y` вниз. Тайл `(col,row)` занимает
  `x ∈ [col*32, col*32+32)`, `y ∈ [row*32, row*32+32)`.
- **Актор**: `x` — центр по горизонтали, `y` — низ (ноги). AABB:
  `[x-w/2, y-h] … [x+w/2, y]`.
- Гравитация `1800 px/с²`, терминальная скорость `900`, coyote `0.10 с`, jump-buffer `0.12 с`.
- Твёрдые тайлы: `#`, `=`, закрытые двери. Платформы-сущности тоже твёрдые.
- Неактивные викинги **замирают** (гравитация и анимация стоят) — это классика и основа пазлов.

### Викинги (сиквел: новые способности)

| | Эрик Быстрый | Балеог Свирепый | Олаф Могучий |
|---|---|---|---|
| Размер (w×h) | 24×44 | 26×46 | 32×40 |
| Бег | 300 px/с | 220 | 180 |
| Прыжок | −630 (≈3.4 клетки) | не умеет | −510 (≈2.2) |
| Способность 1 | **Таран** (`J`): ломает лёд `=`, бьёт врагов | **Меч** (`J`): урон, переключает рычаг вблизи | **Щит** (`J`, удерж.): блок, платформа |
| Способность 2 | **Парение** (держать `Space` в падении): vy ≤ 110, управление сохраняется | **Лук** (`K`): стрела, 620 px/с; по `↑` — вверх; зажигает рычаги | — |
| Способность 3 | — | **Крюк** (`L`): 7 клеток, цепляет твёрдое/`G`; подтягивает 320 px/с; `L` — отцепиться | — |

- Лазание по `L`-тайлам умеют все (скорость 140).
- **Щит Олафа**: пока щит поднят, сверху создаётся односторонняя платформа
  `x±20`, `y-h-6`, высота 8; на неё встают другие викинги. Блокирует снаряды,
  падение замедляется до 70 px/с. Состояние сохраняется при переключении.
- **Крюк Балеога**: летит вверх (если `↑`) или по направлению взгляда, цепляется
  за твёрдый тайл/якорь; подтягивает к точке; автоотцеп при упоре/достижении; повторный `L` — отцепиться.
- Урон: контакт врага = 1, снаряд = 1, шипы = 1 + подброс. Неуязвимость 1.2 с.
  HP у каждого 3. HP = 0 → смерть, респавн у последнего чекпоинта через 1.4 с с полным HP.
  Лава `~` и падение за нижнюю границу мира = мгновенная смерть.
- Каждый вход в портал выхода «забирает» викинга (`exited`). Уровень завершён,
  когда все трое вошли. Портал 2×2 тайла.
- Руны (`rune`): 3 на уровень, +150 очков. Чекпоинты: 1–3 на уровень.

## 2. Схема уровня (`js/levels.js`) — владелец level-smith

```js
window.LV = window.LV || {};
LV.LEVELS = [
  {
    name: "Пробуждение",          // RU, ≤ 26 символов
    nameEn: "Awakening",          // EN, ≤ 26
    hint: "…",                    // RU, ≤ 140 символов (показывается в брифинге и по H)
    hintEn: "…",
    music: 0,                     // 0 | 1 | 2 — игровой трек
    rows: [ "…", ... ],           // 18–30 строк, ширина cols, только ASCII из таблицы
    spawn: { erik: [2,15], baleog: [4,15], olaf: [6,15] }, // [col,row] — клетка, где СТОИТ викинг
    entities: [ /* см. ниже */ ],
    walkthrough: [ "шаг 1", "шаг 2" ] // RU, для QA/README, в игру не выводится целиком
  }
];
```

### Тайлы

| Символ | Значение |
|---|---|
| `.` | воздух |
| `#` | твёрдый камень/лёд |
| `=` | ломаемый лёд: твёрдый, Эрик таранит одним ударом → воздух |
| `^` | шипы: не твёрдые, 1 урон + подброс |
| `~` | лава: не твёрдая, мгновенная смерть |
| `L` | лестница: не твёрдая, лазание |
| `G` | якорь крюка: воздух, подсвечивается |
| `T` | факел: воздух, декор/свет |

### Сущности (координаты — в тайлах, `x` — колонка, `y` — строка)

```js
{type:"plate", x:10, y:15, group:"a"}                  // нажимная плита 1×1; нажать можно стоя
{type:"door", x:20, y:12, w:1, h:3, group:"a"}         // энерговорота; закрыта = твёрдая
{type:"lever", x:25, y:13, group:"b"}                  // рычаг 1×1: стрела/меч → переключить
{type:"platform", x:14, y:10, w:3, dx:0, dy:-4, speed:1.6} // движущаяся платформа, тайлы/с, пинг-понг
{type:"enemy", x:30, y:15, kind:"grunt", range:4}      // grunt | thrower | bat
{type:"rune", x:33, y:8}
{type:"checkpoint", x:8, y:14}
{type:"exit", x:44, y:13, w:2, h:2}
{type:"sign", x:5, y:14, ru:"…", en:"…"}               // камень с подсказкой, тост при подходе
{type:"torch", x:7, y:12}
{type:"anchor", x:18, y:9}                             // визуальный якорь (крюк цепляет и обычный потолок)
```

### Требования к уровням

1. Ровно **6 уровней**. `rows.length` 18–30, все строки одной длины (48–80), только тайлы из таблицы.
2. Спавны: ровно 3, стоят на опоре (под клеткой твёрдое/платформа), клетка свободна.
3. Ровно 1 `exit`; 3 `rune`; 1–3 `checkpoint`; минимум 1 `sign` в обучающих уровнях.
4. Каждая группа дверей (`a`–`d`) связана минимум с одной плитой или рычагом;
   каждая плита/рычаг имеет свою группу с дверью. Плиты и рычаги достижимы.
5. Выход достижим **для каждого** из трёх викингов с учётом способностей; уровень
   проходим и не имеет тупиков-ловушек. Если сомневаешься — упрости.
6. Кривая сложности: 1 — обучение; 2 — лёд + крюк; 3 — лава/враги/платформы;
   4 — вертикаль (парение, крюк); 5 — комбинированный; 6 — финал.
7. Уровень должен **обучать через геометрию**, а не только текстом. Тексты — RU + EN.
8. `walkthrough` — пошаговое прохождение (5–15 шагов), обязательное для QA.

Валидатор `tools/validate-levels.mjs` (node, без зависимостей): проверяет пункты 1–4,
спавны, границы, группы, достижимость выхода BFS-эвристикой (прыжок ≤3 клеток вверх,
падение, лестницы, двери открыты). Должен печатать `OK: 6 уровней` и завершаться кодом 0.

## 3. Состояние мира для рендера (`game.world`)

`render.js` **читает** это состояние и не мутирует его. Все координаты — мировые пиксели.

```js
world = {
  levelIndex, levelCount,
  cols, rows, tile: 32, width, height,
  time,                    // секунды с начала уровня
  globalTime,              // общее время для анимаций
  camera: {x, y, w: 1024, h: 576, shake: 0},   // x,y — левый верхний угол в мире; shake 0..1
  actors: [                // ровно 3, в порядке erik, baleog, olaf
    { id:"erik", active:true, exited:false, dead:false,
      x, y, w, h, dir:1, vx, vy, onGround:true,
      state:"idle",        // idle|run|jump|fall|climb|act|shoot|hook|hurt|dead|exit
      anim,                // фаза анимации (сек)
      hp, maxHp, invuln,
      shieldUp:false, glide:false,
      attack:null,         // {kind:"headbutt"|"sword", t:0..1} | null
      aimUp:false,
      hook:null            // {state:"shoot"|"attached"|"retract", ax, ay, bx, by} | null
    }, …
  ],
  enemies: [ {kind, x, y, w, h, dir, state, anim, hp, active} ],
  props: [                 // все сущности уровня; рендер рисует по type
    {type:"plate", x, y, w, h, group, pressed},
    {type:"door", x, y, w, h, group, open:0..1},
    {type:"lever", x, y, w, h, group, on},
    {type:"platform", x, y, w, h, ox, oy},
    {type:"rune", x, y, w, h, taken},
    {type:"checkpoint", x, y, w, h, active},
    {type:"exit", x, y, w, h, collected:0..3, total:3},
    {type:"sign", x, y, w, h},
    {type:"anchor", x, y, w, h},
    {type:"torch", x, y, w, h, seed}
  ],
  exit: {x, y, w, h, collected, total},
  runes: {got, total},
  projectiles: [           // стрелы и снаряды врагов
    {kind:"arrow"|"shot", x, y, vx, vy, dir, life}
  ]
}
```

Враги: `x` — центр, `y` — низ (ноги), `w/h`; `active:false` — не рисовать.
`world.props[]` содержит все сущности уровня, включая `exit`; координаты — мировые пиксели.
`camera.shake` 0..1 — тряска, `camera.x/y` уже сглажены движком (рендер только читает).

Тайлы: `game.getTile(col,row) → "."|"#"|"="|"^"|"~"|"L"|"G"|"T"` (для рендера;
ломаный лёд возвращается как `"."`).

### События игры → звук и эффекты

`game.setEventSink(fn)`; main передаёт события в `LV.audio.sfx` и `LV.render.addFx`.
Событие: `{type, x?, y?, actor?, text?}`. Типы (= имена SFX):

`jump, land, step, switch, headbutt, break, sword, bow, arrowHit, hookShoot, hookHit,
hookDetach, lever, plateOn, plateOff, doorOpen, doorClose, rune, checkpoint, hurt, death,
respawn, block, enemyHit, enemyDie, exit, lava, win, lose`.

Особые: `{type:"toast", text, tone}` — UI-тост (подсказка знака); `{type:"levelComplete"}`.

## 5. `render.js` (visuals-smith)

```js
LV.render = {
  init(canvas),                  // canvas — <canvas id="game">; настроить размеры/DPR
  setMode("aurora"|"retro"),     // идемпотентно; можно до init — запомнить
  getMode(),
  draw(game, dt),                // всё поле: фон, тайлы, сущности, викинги, эффекты
  addFx(ev),                     // косметические частицы/вспышки по событиям §3
  drawPortrait(canvas, actorId), // маленький портрет для HUD; может быть no-op
  resize()                       // по resize окна
};
```

Требования:

- **AURORA (современный)**: полярное небо с живой авророй, 3+ слоя
  параллакса, снег, объёмный свет, rim-light на камнях, эмиссивная лава/руны,
  мягкие тени и свечение, кинематографичная виньетка. Спрайты — гладкие векторные,
  с анимацией: бег, прыжок, плащ, щит, крюк, атака. Читаемость силуэтов на 1024×576.
- **RETRO (8-BIT) — режим по умолчанию**: внутренний рендер 512×288 (ctx.scale(0.5)) → CSS `image-rendering:
  pixelated`. Ограниченная палитра, дизеринг, минимум сглаживаний, CRT-скан-линии/виньетка,
  «Sega Saturn 1997» вайб. Без современных градиентов и blur.
- Камера: рисуется только видимая область; уровни до 80×30; тряска из `world.camera.shake`.
- Неактивные викинги: приглушённый «голографический» контур + номер 1/2/3, чтобы игрок
  помнил, где они. Активный — подсветка/маркер.
- Двери, плиты, рычаги, руны, чекпоинты, портал, платформы, якоря, знаки, факелы — всё читаемо
  и различимо в обоих режимах; состояния (открыто/нажато/взято) видны.
- Переключение режима — мгновенное, с коротким «глитч»-переходом ~250 мс.
- Производительность: 60 fps в 1440×900; статичные слои кэшировать в offscreen-canvas,
  не использовать `shadowBlur` на каждой клетке; не создавать объекты в цикле отрисовки
  без нужды. Снап координат к сетке в retro.
- `LV.render` не зависит от DOM/HUD/меню; рисует только canvas игры.
- До появления `game.js` визуал можно отлаживать на своём `tools/render-preview.html`
  (мок `game.world` из этого контракта; файл твой).

## 6. `audio.js` (audio-smith)

```js
LV.audio = {
  unlock(),                    // создать/resume AudioContext; вызывать на первом жесте
  isReady(),
  playMusic(id),               // 'title' | 'game0' | 'game1' | 'game2' | 'ending' | 'none'
  stopMusic(fade),             // плавно, без щелчков
  pauseMusic() / resumeMusic(),
  sfx(name),                   // см. список в §3; безопасно до unlock
  setMuted(b), toggleMuted(), getMuted(),
  setVolume(v)                 // 0..1
};
```

- Оригинальные мелодии (не копировать темы из игр!). Чиптюн: 2 пульсовых канала
  (duty 12.5/25/50), треугольный бас, шумовые барабаны + арпеджио. Скандинавский лад
  (дорийский/минор), «драккар-бит»: title — 90 BPM атмосфера; game0 — 132 BPM A-moll;
  game1 — 140 BPM E-moll; game2 — 120 BPM D-moll; ending — 100 BPM тёплый.
- 8–16 тактов, развитие, бесшовный луп, плавный fade при смене трека; громкость
  сбалансирована, мастер-компрессор; не клиппит; хорошо в наушниках.
- Планировщик по lookahead (setInterval 25 мс, горизонт 0.1 с), корректная очистка,
  остановка осцилляторов, никаких утечек. Работает в Chrome/Safari/Firefox.
- SFX: короткие, читаемые, разные; UI-звуки `uiMove/uiClick/uiBack`.
- `node --check js/audio.js` + `tools/audio-test.mjs` (заглушка AudioContext) — зелёные.

## 7. `ui.js` + `index.html` + `css/style.css` + `i18n.js` (ui-smith)

### API

```js
LV.ui = {
  init({callbacks, getState}),   // callbacks — см. ниже
  screen(name, data),            // 'title'|'levels'|'brief'|'play'|'pause'|'complete'|'ending'|'help'

  toast(text, opts),             // {tone:'info'|'warn'|'success', duration}
  setMode(mode), setLang(lang), setMuted(muted),
  setSaveInfo({unlocked, hasProgress})
};
```

Колбэки (вызывает UI, обрабатывает main):
`onStartNew, onContinue, onSelectLevel(index), onBeginLevel(), onResume, onRestart,
onNextLevel, onReplay, onQuitToTitle, onToggleGraphics, onToggleLang, onToggleMute,
onOpenHelp, onCloseHelp, onPause, onInput(action, down)`.

Кнопка «В путь» на брифинге вызывает `onBeginLevel` (допустим и `onSelectLevel(index)` —
main понимает оба варианта).

### Экраны

1. **title** — логотип `LOST VIKINGS` / `II · NORSE BY NORSEWEST`, RU-подзаголовок,
   кнопки «Новая игра», «Продолжить» (если есть прогресс), «Уровни», «Управление»,
   чипы графики/языка/звука. Живой аврора-фон на CSS, без тяжёлых эффектов.
2. **levels** — 6 карточек: номер, название RU/EN, руны 0–3, время, замок на неоткрытых.
3. **brief** — номер и название уровня, подсказка, новые механики (иконки/текст), «В путь».
4. **play** — HUD: уровень/название, руны 0/3, таймер, смерти; панель трёх викингов
   (портрет, HP-сердца, активный, способности); счётчик выхода 0/3; подсказки управления.
5. **pause** — продолжить/заново/настройки/выход; музыка приглушается.
6. **complete** — статистика уровня: время, смерти, руны, очки; «Дальше».
7. **ending** — финальная статистика прохождения, стильные титры, «В меню».
8. **help** — управление, способности, советы; закрывается `Esc`/кнопкой.

### Требования

- RU по умолчанию, полный EN-переключатель (`LV.i18n`), выбор сохраняется.
- `LV.ui.screen()` показывает/скрывает экраны без перезагрузки; `body[data-screen]` и
  `body.mode-aurora|mode-retro` для CSS.
- HUD обновляется без layout-thrash; числа меняются только при изменении.
- Адаптив: desktop (1440×900), ноутбук (1280×800), планшет, телефон 390×844.
  На тач-устройствах — экранные кнопки (←→↑↓, прыжок, действие, спец, крюк, смена викинга),
  они зовут `onInput(action, down)`. Без тача — скрыты.
- Доступность: видимый focus, aria-label у кнопок, `aria-live` для тостов, работа с клавиатуры.
- Никаких эмодзи, внешних иконок и шрифтов. Декор — CSS/SVG.
- `index.html` обязан корректно грузить все скрипты в порядке §0 и не падать, если
  какой-то модуль ещё заглушка.
- Своя песочница `tools/ui-preview.html` с мок-состоянием — можно и нужно.

## 9. Поток экранов и состояние (main.js)

- `title → (новая игра | продолжить | уровни) → brief(level) → play`.
- Пауза `P`/`Esc`; рестарт `R`; подсказка `H`; смена викинга `1/2/3`/`Tab`;
  графика `G`; звук `M`; язык `Y` (или кнопкой); подтверждение `Enter`.
- Смерть: викинг возрождается у чекпоинта (без экрана game over), счётчик смертей растёт.
- `play`: игра идёт, HUD обновляется; события → звук/эффекты/тосты.
- Завершение уровня → `complete`; последний → `ending`.
- Прогресс в `localStorage`: `lv2.mode` (aurora|retro), `lv2.lang` (ru|en), `lv2.muted`,
  `lv2.progress` = `{unlocked: 1..6, levels: {i: {runes, time, deaths, score}}}`.
  После reload — «Продолжить» с последнего открытого уровня.
- Музыка: title → `title`; уровни 1–2 → `game0`; 3–4 → `game1`; 5–6 → `game2`;
  ending → `ending`; пауза — `pauseMusic()`; выключение звука — `setMuted(true)`.
