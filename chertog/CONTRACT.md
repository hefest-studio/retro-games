# ЧЕРТОГ (GLOAMSTAGE) — контракт модулей

Игра аркады «Гефест» на фреймворке Гефест Arcade v2.10 (`engine.js`). Общий стандарт: офлайн, `file://`, без внешних URL/шрифтов/ассетов, RU/EN/TR/ES/PT,
темы modern/retro (меняют только отрисовку), WebAudio-звук, рекорд в `localStorage`. Название, сеттинг (театр бумажных теней), герой, стражи, декорации,
уровни, палитры, звуки и музыка — оригинальные; чужих имён нет (тест «правило имён»).

## js/levels.js — `CHERTOG.LEVELS[12]`
`{ id, par, lamps, rows }`: `rows` — 8 строк по 16 знаков; ` `/`.` пусто, `#` кладка (даёт тень), `=` плита (твёрдая только в тени), `o` бумажная декорация (даёт тень,
проходима), `S` старт, `E` дверь, `1`/`2`/`3` рычаг лампы с этим номером, `g`/`G` страж (идёт вправо/влево). `lamps[k]` — точки лампы k `[x, y]` по кругу (старт — точка 0).
`par` = длина кратчайшего решения (проверяется тестом).

## js/game.js — `CHERTOG.logic` (без DOM, детерминирована, чистая)
`parse(def)` → `P` (карта `t[]`, рычаги `lev`, дверь, старт, лампы) · `lit(P, lamps)` → `Uint8Array(W*H)`: 1 — клетку видит хоть одна лампа (луч не пересекает `#`/`o`) ·
`init(def)` → состояние `{hx,hy,hf,lamps[],guards[[x,y,d,alive]],moves,dead,won,ev[]}` · `step(P, s, act)` → новое состояние (или тот же объект, если ход невозможен);
`act` ∈ `L R UL UR U A` · `solid`, `dazzled`, `key`, `clone` · `solve(def, {from, limit})` → кратчайший список ходов или `null` (поиск в ширину; `from` — с произвольного состояния — для подсказки).
Правила: плита твёрдая, если не освещена; страж на свету ослеплён (не ходит, безвреден); прыжок — только через яму или ступень, дальность 2 клетки; после хода — падение, затем ходят стражи;
смерть: `caught` (страж), `fall` (пустота), `crush` (плита выросла на месте героя); `won` — герой в клетке двери. События `ev`: `walk step turn jump land lever wait die win`.

## js/render.js — `CHERTOG.render(g, ctx, V)`, `CHERTOG.R`
Канва 512×288: HUD 32 px + поле 16×8 по 32 px. `V = { P, s, hv, gv, lampV, litA, t, retro, hint, ui, fi, total, id, moves, par, score, deadT }`.

## js/main.js
Сцены `title` (перерисована), `play`, `card` (перед межстраничной), стандартные `pause/win`. Пошаговый ввод с анимацией (ход принимается, когда картинка «успокоилась»); отмена — стек состояний;
сохранение `arcade.save.chertog` `{v:2, fi, score}`; миграция — ключ `arcade.chertog.ver`. Площадка: `useLeaderboard('chertog')`, `useNoAds`, `useRewardedBonus` (подсказка), `adBreak`.
Хук для тестов и промо: `CHERTOG.app` (`load(fi, score)`, `act(a)`, `undo()`, `busy()`, `game()`).
