# ПОЛУУСТАВ (GALLWICK)

Оригинальная игра студии «Гефест»: атмосферный пазл-платформер без слов, целиком нарисованный тушью —
гравюра и эскиз пером на бумаге. Ученик переписчика (светлая рубаха, чёрная скуфейка, киноварный пояс, перо за ухом)
бредёт по семи страницам старой рукописи; иллюстрации на полях оживают. Тон — тихая сказка с тревогой, без жестокости:
смерть — клякса, и ученик тут же снова у последней отметки (пером на полях).

## Страницы (≈ 35 головоломок, 30–45 минут при первом прохождении)
1. **Заставка** — шаг, подтягивание, пропасть, ящик у высокой стены, рычаг и затвор, капкан, мелкая яма с капканами (ящик — кочка).
2. **Мельница** — бревно падает за спиной и становится мостом, верёвка, ящик тянуть из угла, пилы мельницы, две верёвки подряд.
3. **Река** — ящик-плот по течению, шлюз-рычаг и свая, бассейн: вода поднимает ящик, рычаг разворачивает течение.
4. **Звонница** — противовес с бункером (ящик перевешивает ученика), пила-бегунок, плита убирает жернова, рычаг-пульс — на время.
5. **Разлив** («ага»: тушь) — песочница сушит лужу туши в опору; капли чернильницы; тушь растекается следом; ящик тонет и становится кочкой; тушь течёт навстречу — остановить её песком.
6. **Перо** («ага»: перо дорисовывает) — мост пера живёт несколько секунд; плита держит его; мостки рисуются по очереди; протащить ящик по временному мосту.
7. **Лампада** («ага»: свет) — карандашные наброски тверды только в свете лампады; стена-набросок пропускает без света (бросок лампады через неё); лестница набросков; финальная верёвка и колофон.

## Управление
◀▶ / A D — идти; ▲ / W / пробел / Z — прыжок (на верёвке ▲▼ — вверх-вниз, прыжок — отпустить); E / X / J / Shift — действие:
рычаг, взять/поставить лампаду, в движении — бросить; держать у ящика и идти от него — тянуть. P — пауза («К последней отметке»
откатывает застрявшую головоломку), T — тема, L — язык, M — звук. Тач: ◀ ▶, ✋, ▲ и свайп вверх по экрану — прыжок.
Прогресс сохраняется по отметкам (`localStorage` `poluustav.save`), меню «Продолжить».

## Темы
modern — сепия по тёплой бумаге, акварельная подмывка, размытый фон-иллюстрация; retro — строгая гравюра 1-бит:
кадр сводится к двум цветам упорядоченным растром 4×4 в половинном разрешении.

## Файлы
`js/levels.js` — страницы (данные), `js/game.js` — логика и физика (фиксированный шаг 1/120, AABB, без DOM),
`js/render.js` — тушь (перо, штриховка, кэш тверди кусками), `js/audio.js` — звук среды (шаги пера, шорох страниц, плеск),
`js/music.js` — процедурный эмбиент по страницам, `js/main.js` — сборка. Отладка: `#z=<0..6>&cp=<отметка>`.

## Тесты
