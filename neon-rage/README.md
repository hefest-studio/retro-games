# НЕОН × ЯРОСТЬ · Neon Rage

Оригинальный браузерный beat 'em up студии **«Гефест»**: **Кай-Комета** и киборг-кузнец **Рок-Молот**
выбивают украденный чип `NEON-8` из лап корпорации «ТОКСИК». Неоновый город,
три квартала, пять волн и корпоративный ИИ ХРОМ-9 на крыше башни.

Работает офлайн: вся графика рисуется кодом на Canvas 2D, вся музыка и звуки
синтезируются WebAudio — без картинок, шрифтов, аудиофайлов и CDN.

## Движок v2 («хост поверх игры»)

С волны 2 игра работает на фреймворке Гефест Arcade v2 по схеме `obval/`, `rubikon/`, `vihr/`:
родная игра (`js/game.js`, собрана из `src/`) идёт своим циклом и рисует сама, а прозрачный
canvas движка (`engine.js` + `js/host.js`) лежит ровно над кадром игры и даёт стандарт аркады:

* меню **Играть / Управление / Настройки / Язык / Тема / Звук** и рекорд, пауза, экраны финала;
* **Играть** → родной выбор героя и сложности → сюжет («ESC — пропустить») → бой;
  на родных экранах игры движок прозрачен и отдаёт им ввод (Esc — «назад»/«пропустить» самой игры);
* тема движка `retro` / `modern` ⇄ графика игры `8-БИТ` / `НЕОН` (`DD.settings.gfx`), modern — по умолчанию;
* язык движка ⇄ язык игры (`DD.settings.lang`); звук движка ⇄ музыка + эффекты игры;
* пауза движка замораживает бой (родное меню паузы игры под ней не рисуется);
  тач-кнопка `II` и скрытие вкладки ставят паузу через движок;
* рекорд — `arcade.best.neon-rage`; старый рекорд (`dd-neon-settings-v1` → `best`) переносится при первом запуске;
* своя музыка игры (чиптюн / синтвейв) оставлена, `js/music.js` движка не используется.

Старая автономная версия (один файл) — `legacy.html`.

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` `↑` `↓` / `WASD` | движение по арене, навигация в меню |
| `SPACE` | прыжок (в меню — выбор) |
| `J` / `Z` | удар, серия из трёх |
| `K` / `X` | пинок, тяжёлый |
| `V` | спецприём при полной шкале ярости |
| `ENTER` | подтвердить / старт |
| `P` / `ESC` | пауза; на экранах игры — назад, пропустить сюжет |
| `T` / `G` | тема: `retro` (8-БИТ) ↔ `modern` (НЕОН) |
| `L` | язык: РУ ↔ EN |
| `M` | звук (музыка и эффекты) вкл/выкл |
| `F` | полный экран |

Раскладка сведена со стандартом аркады: раньше `T` был языком, а `L` — спецприёмом.
Теперь `L` — язык, `T` — тема (как в движке), спецприём — `V` (тач-кнопка `★ V`).

На телефоне — экранные кнопки: крестовина слева, удар/пинок/прыжок/ярость справа, `II` — пауза.

## Возможности

* **Боевая система**: серии ударов, пинки, атаки в прыжке, комбо-множитель,
  шкала ярости и спецприёмы. У Кая — «Огненное кольцо», у Рока — «Земляной слэм».
* **Три зоны**: Неоновый проспект → Аркадный переулок → крыша «ТОКСИК».
  Гопники, ниндзя, бугаи; ящики и автоматы с едой и монетами.
* **Финальный босс** — ИИ ХРОМ-9 в теле промышленного погрузчика: силовой кабель с захватом,
  веер энергошаров, удар о землю, призыв ниндзя на второй фазе.
* **Сложность** `ЛЕГКО / НОРМА / ХАРД` (выбор героя или «Настройки») влияет на HP, урон
  и скорость врагов, а также на множитель очков.
* **Настройки игры** (пункт меню «Настройки»): стиль музыки 8-БИТ / СИНТВЕЙВ, громкость, CRT-фильтр,
  сложность, сброс рекорда игры.

## Параметры адреса (отладка, превью каталога)

`#gfx=retro|modern`, `#lang=ru|en`, `#scene=<режим>`, `#wave=<n>`, `#demo=1`, `#freeze=1`, `#touch=1`.
Если игра по ним сразу оказывается в бою или на своём экране (`#demo=1`, `#scene=intro` …),
движок не показывает меню, а следует за ней. `tools/thumbs.mjs` снимает превью по `#gfx=<тема>&demo=1`.

## Разработка

* Логическая сцена — **480×270** (16:9); canvas движка — 704×396 той же пропорции.
* Исходники — `src/` (font, i18n, audio, game, render-retro, render-modern, main, style).
  Сборка: `node neon-rage/tools/build.mjs` → `js/game.js` + `css/style.css`.
  `index.html` (разметка, подключение движка и адаптер `window.DD` → host) правится вручную.
* Контракт модулей и ключи локализации — `docs/CONTRACT.md`.
* Тесты оболочки: `node neon-rage/tests/engine.test.mjs` (Playwright).
