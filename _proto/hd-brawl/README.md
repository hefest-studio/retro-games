# МЕДНАЯ СЛОБОДА · прототип драки «чиби HD-пиксель»

Прототип оформления студии «Гефест» (не игра). Ночная улица мастерских: медь, кирпич, пар. Подмастерье в фартуке и
очках-консервах против кочегаров в респираторах (один вид, две палитры: стальная и ржавая жилетка).

Запуск: из корня репо `python3 -m http.server 8561` → <http://localhost:8561/_proto/hd-brawl/> (`?lang=en`).

## Как сделана графика
- **Спрайты — матрицы индексов палитры** (`js/sprites.js`): детали (голова, туловище, руки, ноги) записаны строками
  символов, легенда `KEY` → индекс в `PAL`. Кадр 40×48 собирается из деталей целыми сдвигами; допустимы только
  зеркало и поворот на 90° (без потерь). Дальний план (рука/нога за телом) — перекраска на ступень темнее (`SHADE`).
- **Селективный контур** добавляется к готовому кадру: снизу/справа — чернила `#141013`, на освещённой кромке (сверху/слева) —
  на ступень темнее цвета материала (`LIT`). Деталь «поверх» (ближняя рука, голова) получает внутренний контур сливой.
- **Палитра — 16 цветов на весь прототип** (персонажи, фон, пар, искры, HUD); рампы со сдвигом оттенка
  (тени — в лиловый/холод, света — в жёлтый). Враг-вариант — та же матрица с перекраской индексов.
- **Фон** (`js/world.js`) рисуется прямо пикселями палитры в 3 слоя параллакса (0.22 / 0.55 / 1.0); пар — частицы-клубы
  двух тонов из видимых источников: трубы заводов и мастерских, клапаны трубопровода, решётки мостовой.
- Холст 480×270, масштаб страницы только целый (×1…×4), `imageSmoothingEnabled=false`, `image-rendering: pixelated`.

## Кадры
idle ×2, walk ×4, удары: джеб, кросс, пинок (валит), прыжок (+удар в воздухе — пинок), урон, падение (полёт), лежит.

## Управление
Стрелки/WASD — ход по X и вглубь (Z) · Пробел/J/X — удар (серия из трёх) · K/Z/C — прыжок · P — пауза · T — тема · L — язык.
Тач: стик + ● удар + ⤒ прыжок, II — пауза (`Arcade.touchOk`).

## Ощущение удара
Хит-стоп 3–4 кадра (бойцы замирают, искры и пар живут), тряска в целых пикселях, белая вспышка силуэта (тот же спрайт,
все цвета кроме контура → белый), пиксельные искры, кольцо-вспышка, цифры урона шрифтом 3×5.

## Тесты
`node _proto/hd-brawl/tests/sprites.test.mjs` — палитра ≤16, все кадры, опора кадра, варианты врага.
Крючки для браузерных проверок: `window.__hb` (`stage()`, `manual()`, `step(n, input)`, `fps()`).
