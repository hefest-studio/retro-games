# ПОРУБЕЖЬЕ — прототип RTS с асимметричными расами

Прототип для оценки: одна карта 64×48, две играбельные расы, игрок против ИИ другой расы, партия ~8–15 минут.
Мир: сказочный северный порубежный край: бор, вереск, озёра, медь и дерево у одних, мох, кора и грибница у других.
Космоса, пехоты в скафандрах, «слизи» и светящихся кристаллов-энергостанций здесь нет.

Запуск: `python3 -m http.server 8352` в корне репо, затем открыть `http://localhost:8352/_proto/rts-b/` (`?lang=en` — английский).
Тесты: `node _proto/rts-b/tests/engine.test.mjs` (логика, без браузера, ~8 с).

## Управление
| Мышь | Действие |
|---|---|
| ЛКМ | выбрать; протяжка — рамка; Shift — добавить или снять; двойной клик или Ctrl+клик — все такие же на экране |
| ПКМ | умный приказ: враг → атака, месторождение → добыча, своя недостройка → достроить, своё повреждённое (Мастеровые) → ремонт, земля → идти; у здания — точка сбора (на месторождении рабочие сразу идут добывать) |
| A, затем ЛКМ | атака с ходу (Shift — оставить режим) |
| край экрана, стрелки, колесо (Shift+колесо — по горизонтали), протяжка средней кнопкой | камера |
| мини-карта | ЛКМ или протяжка — камера, ПКМ — приказ в точку |
| Q W E R | стройка (выбран рабочий) / обучение (выбрано здание); A — атака, S — стоп, X — отмена |
| Ctrl+1..9 / 1..9 / дважды 1..9 / Shift+1..9 | назначить отряд / выбрать / камера к отряду / добавить к выбору (отряды ещё и в верхней строке: клик выбирает, Ctrl+клик или ПКМ назначает) |
| Пробел / H | камера к выбранным / к главному зданию; Esc — отменить режим или снять выбор (без режима и выбора — пауза) |
| Тач | тап — выбор, протяжка — рамка, два пальца — камера, долгий тап (0,5 с) — приказ, кнопки панели — тапом, «II» — пауза |

Курсор меняется по ситуации: атака, атака с ходу, добыча, ремонт, движение, стройка, мини-карта.
Движок общие P / L / T / M (пауза, язык, тема, звук).

## Расы
**Мастеровые** (медь и дерево). Строят рабочими: здание растёт, только пока рядом стоит подмастерье (троим быстрее). Здания и шагоход чинятся (ПКМ рабочим). Сами раны не заживают.
- Подмастерье: добыча, стройка, ремонт. Пищальник: стрелок, дальность 5. Топотун: паровой шагоход, броня, пушка с разлётом, чинится.
- Острог (склад, +10 провизии), Изба (+8), Стрельня (пищальники), Котельня (топотуны, нужна стрельня).

**Живая чаща** (мох, кора, янтарные глаза). Короед сажает росток и сразу свободен, росток вырастает сам. Сажать можно только на **грибнице**: она расходится от Пня-матери и дупел и растёт вместе с ними. Пень-матерь можно посадить где угодно. Бойцы вылупляются из **личинок** Пня (до 3, +1 за 8 с), по нескольку сразу. Раны юнитов и зданий заживают сами.
- Короед: добыча, посадка. Жалильщик: быстрый мшистый клубок, жалит вблизи (нужен жальник). Панцирник: мшистый панцирь, мечет шипы с разлётом (нужен курган).
- Пень-матерь (склад, личинки, +10), Дупло (+8, грибница), Жальник, Мшаный курган.

Экономика у обеих рас: **янтарь** (россыпи, 5 за ходку) и **смола** (смоляной ключ, 4 за ходку). Лимит **провизии** до 60.

### Третья раса (план, не реализована): **Курганный род** (каменотёсы с перевалов)
- Здания — каменные идолы, ставятся только рядом с валунами или на скальной гряде (зеркально грибнице: зависят от рельефа, а не от растущей зоны).
- Юниты собираются из глыб у главного идола. Замерев, «каменеют»: броня растёт, двигаться нельзя. Это оборонительная раса.
- Ресурсы те же, но вместо провизии — «очаги» (каждый греет ограниченный круг юнитов рядом).
- Юниты: Каменщик (рабочий, катит глыбы), Пращник (дальний), Валун-страж (медленный таран, раскатывается по прямой).

## Устройство
| файл | что |
|---|---|
| `js/game.js` | логика без DOM: карта (центрально-симметричная, проверка связности), A* (8 направлений, без срезания углов, частичный путь к недостижимой цели, сглаживание по прямой видимости), юниты, здания, бой, расталкивание, грибница, туман, ИИ |
| `js/mouse.js` | **модуль мыши и тача, не зависит от игры**: Pointer Events → клик, двойной клик, рамка, ПКМ, колесо, панорама (СКМ, два пальца), долгий тап, UI-зоны, край экрана, набор SVG-курсоров. API: `ArcadeMouse.attach(canvas, {W,H,enabled,hitUI,onClick,onBoxStart,onBox,onBoxEnd,onRight,onWheel,onPan,onHover,onUi})` → `{x,y,inside,box,edge(),setCursor(),busy(),detach()}`. Готов к выносу в `_shared` |
| `js/render.js` | отрисовка: modern — гладко, тени, мягкий туман; retro — ступенчатые «пиксельные» формы, блочный туман |
| `js/main.js` | связка с движком: камера, HUD, панель команд, горячие клавиши, отряды, уведомления |
| `js/i18n.js`, `js/music.js` | строки RU/EN, оригинальная мелодия |

ИИ: строит по расписанию (дом → казарма → дом → тяжёлое здание…), держит 3–4 рабочих на смоле, ставит дома при нехватке провизии, при лишнем янтаре строит вторую казарму (Мастеровые) или второй Пень (Чаща), обороняется и с 5-й минуты атакует волнами (5 бойцов, затем +3 каждые ~100 с).
Упрощения: ИИ видит всю карту (без тумана), ремонт бесплатный, у юнитов нет «удержания позиции» и патруля, лес непроходим и не вырубается.

Ссылка «← Каталог» ведёт на `../../` (прототип лежит в `_proto/rts-b/`). При переносе в корень как отдельной игры нужно поменять на `../` и добавить в каталог.
