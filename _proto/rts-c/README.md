# ГАТЬ — прототип лёгкой стратегии «от героя» (тач + мышь)

Прототип для оценки (не полная игра) студии «Гефест». Болотный край: **Гатевая стража** (бирюза, лён, янтарные фонари) держит
старые мостки-гати против **болотной нечисти** (сливово-бурые твари с лаймовыми глазами). Базы и экономики-стройки нет:
герой и 2–4 отряда захватывают **вехи** на островах. 3 миссии по 8–12 минут.

Запуск: `python3 -m http.server 8355` в корне репо → <http://localhost:8355/_proto/rts-c/> (`?lang=en`).
Для плейтеста: `?mission=1..3` (сразу в бой), `&hero=v|z`, `&seed=N`, `&bot=1` (играет бот).

## Правила
- **Вехи.** Отряд на ничьей вехе захватывает её за ~5 с (+30 припаса). Веха с **гнездом** не захватывается, пока гнездо цело
  (гнездо подращивает стражу). Своя веха даёт припас (+0.4/с, с амбаром +0.75/с), лечит и пополняет отряды, стоящие на ней.
  Нечисть, стоящая на вехе без защитников, отбивает её за 10 с (постройка теряется). **Падение сторожки — поражение.**
- **Панель вехи** (тап/клик по столбу): найм отряда (самострельщики 80 — стрелки, щитники 90 — броня вблизи, лафеты 130 —
  лёгкая техника с разлётом), улучшение отряда, стоящего на вехе (ур. 2–3: +25% здоровья, +20% урона, пополнение),
  одна постройка: **вышка** (стреляет), **костёр** (лечит и быстрее пополняет), **амбар** (доход). Не больше 4 отрядов.
- **Герой** (выбор перед миссией), растёт до ур. 5 от убийств (здоровье, урон, перезарядка), павший возвращается через 10 с.
  - Ведана-фонарщица — стрелок. **Q** «Залп» — огненный удар по месту (радиус 75), **E** «Свет» — лечит своих рядом.
  - Ждан-багорщик — крепкий, вблизи. **Q** «Рывок» — бросок до 260 px с ударом и отбросом, **E** «Клич» — свои рядом 6 с бьют на 40% сильнее и чаще.
- **Нечисть:** стража гнёзд, волны из омутов (растут с каждой волной), мини-босс: поднимается, когда гнёзда разорены
  (но не раньше 7–8-й минуты) или по таймеру. Коряжник (удар по площади, зовёт кочкарей), Камышница (дальний бой, град плевков),
  Омутник (затягивает всех вокруг, зовёт тинников). Победа — босс повержен. Звёзды: победа · герой не падал · за 10 минут.
- Миссии открываются по порядку (`arcade.gat.progress`, звёзды — `arcade.gat.stars.N`, герой — `arcade.gat.hero`; всё в try/catch).

## Управление
| | |
|---|---|
| **Тач** | тап по отряду/карточке — выбор; тап по земле — идти и бить (атака с ходу), по врагу — атака, **двойной тап** — идти без боя; протяжка — камера, щипок — зум; тап по столбу вехи — панель; крупные кнопки Q/E (Q — прицел, затем тап по карте); «Все» — выбрать всех; «+» — найм |
| **Мышь** | ЛКМ — выбор, протяжка ЛКМ — рамка, Shift+ЛКМ — добавить/снять; ПКМ — приказ (дважды — без боя); колесо — зум; СКМ — панорама; клик по мини-карте — камера; ЛКМ по вехе — панель |
| **Клавиатура** | 1–4 — отряды, H / 0 / \` — герой (дважды — камера), Пробел — все; Q — способность в точку курсора, E — вторая; WASD/стрелки — камера, +/− — зум; Tab — следующая своя веха, Z X C — найм, V — улучшить, R F G — вышка/костёр/амбар; Esc — отменить прицел/закрыть панель/пауза; общие P, L, T, M |

## Устройство
| файл | что |
|---|---|
| `js/missions.js` | миссии данными: острова, гати, броды, волны, стража, босс |
| `js/game.js` | логика без DOM (`GAT.logic`): генератор карты, A* (8 направлений, без срезания углов, стоимость клеток: мель/камыш медленнее, гать быстрее; сглаживание «не дороже пути»), отряды строем (якорь по пути + места в строю по направлению движения), бой, вехи, нечисть, босс |
| `js/bot.js` | бот-игрок (реакция 150–250 мс) через тот же API, что и ввод |
| `js/render.js` | мир: modern — мягкие берега, доски гатей, тени, свет фонарей; retro — кадр в буфере 1/3 своей палитрой |
| `js/main.js` | сцены (заставка движка → поход → бой → итог), камера, HUD, Pointer Events (тач/мышь), клавиши, звук событий |
| `js/i18n.js`, `js/music.js` | RU/EN; оригинальный наигрыш (ре дорийский, 8 тактов) |
| `engine.js` | копия `_shared/engine.js` |

Холст: высота 720, ширина 1000–1600 по пропорции экрана (на телефоне 844×390 — 1557×720, кнопки способностей ~80 css px).

## Тесты
- `node _proto/rts-c/tests/engine.test.mjs` — карта/A*, строй, захват, найм/улучшение/постройки, способности и уровень героя,
  возрождение, **бот проходит миссию 1** (оба героя, 3 сида, ~8 мин), музыка, RU/EN, страница, правило имён (стоп-лист в base64).
- `node _proto/rts-c/tests/browser.mjs [папка]` — Playwright: мышь/клавиатура (1280×720) и тач (844×390: `page.touchscreen` + CDP
  для протяжки и щипка), 0 ошибок; с папкой — скриншоты `rts-c-{modern,retro,phone}.png` (порт `PORT`, по умолчанию 8355).
