# ПРИИСК · прототип стратегии в реальном времени

Прототип для оценки (не полная игра) студии «Гефест». Северное плато, две артели старателей делят медь:
**Артель Медного Ключа** (игрок, латунь) против **Артели Сизого Перевала** (ИИ, сирень). Медь и пар.
Одна карта 64×48 (сид — случайный или `?seed=N`), партия 10–15 минут. Победа — снести Контору соседей.

## Запуск
Из корня репо: `python3 -m http.server 8351` → <http://localhost:8351/_proto/rts-a/> (`?lang=en`, `?seed=5`).

## Мир и правила
- **Здания:** Контора (старт, строит остальное, пар +10), Котельная (пар +20), Барак, Плавильня (приходит со своим рудовозом), Паровая мастерская.
- **Юниты:** Стрелок, Самоход (лёгкий), Броневоз (тяжёлый), Рудовоз.
- **Экономика:** рудовоз копает самородки в отвалах и везёт на площадку Плавильни → медь. Медь списывается при заказе, отмена (ПКМ по кнопке) возвращает.
- **Пар:** если расход больше выработки — стройка и производство ×0.4.
- **Стройка:** заказ в панели → по готовности призрак здания по сетке (зелёный/красный), не на занятое/скалу/медь/юнитов и не дальше 4 клеток от своих зданий.
- **ИИ:** строит базу по списку, держит 2 рудовоза, копит армию, с 4.5 минуты шлёт волны (каждые 2.5 мин, растут), обороняется.
- A* по сетке (8 направлений без срезания углов, сглаживание), расталкивание, туман (не открыто / видели / видно).

## Управление
- **Мышь:** ЛКМ — выбор; рамка — группа; Shift — добавить/снять; двойной клик — все такие же на экране; ПКМ — идти / атаковать / копать / везти на плавильню (у выбранного Барака/Мастерской — точка сбора); курсор меняется (идти, атака, кирка, «нельзя»). Камера: край экрана, стрелки/WASD, колесо (Shift — по горизонтали), средняя кнопка, клик/протяжка по мини-карте; ПКМ по мини-карте — приказ.
- **Клавиши:** Ctrl+1…9 (или Alt+1…9) — назначить группу, 1…9 — вызвать, дважды — камера к группе; H — к Конторе; X — стоп; Пробел — к выделенным; Esc — отменить постановку; P пауза, T тема, L язык, M звук.
- **Тач:** тап — выбор, протяжка — рамка, долгий тап — приказ, два пальца — камера; кнопки панели — тапом, долгий тап — отмена.

## Файлы
- `js/mouse.js` — **ArcadeMouse**: модуль мыши/тача без знания об игре (клик/двойной, рамка, ПКМ, захват для панели, средняя кнопка, колесо, край экрана, тач-жесты, SVG-курсоры). Кандидат на вынос в `_shared/`.
- `js/game.js` — логика без DOM (карта, A*, юниты, экономика, туман, ИИ) — `PRIISK.logic`.
- `js/render.js` — рисование (темы modern/retro), мини-карта, панель. `js/main.js` — склейка с движком. `js/i18n.js` — RU/EN.
- `engine.js` — копия `_shared/engine.js`.

## Тесты
- `node _proto/rts-a/tests/engine.test.mjs` — логика, ArcadeMouse на фейковом canvas, i18n, правило имён (стоп-лист в base64).
- `node _proto/rts-a/tests/browser.mjs [папка]` — Playwright: рамка/ПКМ/двойной клик/группы/курсоры/панель/камера мышью, тач через CDP, 0 ошибок; с папкой — скриншоты `rts-a-{retro,modern}.png`.
