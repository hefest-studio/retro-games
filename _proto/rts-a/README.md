# ПРИИСК · прототип стратегии в реальном времени

Прототип для оценки (не полная игра) студии «Гефест». Северное плато, две артели старателей делят медь:
**Артель Медного Ключа** (игрок, латунь) против **Артели Сизого Перевала** (ИИ, сирень). Медь и пар.
Скирмиш: одна карта 64×48 (сид — случайный или `?seed=N`), партия 10–15 минут, победа — снести Контору соседей.
Кампания «Медная лихорадка» (вертикальный срез): миссии 1–2 Артели Медного Ключа на движке миссий данными.

## Запуск
Из корня репо: `python3 -m http.server 8351` → <http://localhost:8351/_proto/rts-a/> (`?lang=en`, `?seed=5`).
Меню: «Скирмиш» / «Кампания». Для плейтеста: `?mission=m1` или `?mission=m2` — сразу брифинг миссии (прогресс не нужен).

## Мир и правила
- **Здания:** Контора (старт, строит остальное, пар +10), Котельная (пар +20), Барак, Плавильня (приходит со своим рудовозом), Паровая мастерская.
- **Юниты:** Стрелок, Самоход (лёгкий), Броневоз (тяжёлый), Рудовоз.
- **Экономика:** рудовоз копает самородки в отвалах и везёт на площадку Плавильни → медь. Медь списывается при заказе, отмена (ПКМ по кнопке) возвращает.
- **Пар:** если расход больше выработки — стройка и производство ×0.4.
- **Стройка:** заказ в панели → по готовности призрак здания по сетке (зелёный/красный), не на занятое/скалу/медь/юнитов и не дальше 4 клеток от своих зданий.
- **ИИ:** строит базу по списку, держит 2 рудовоза, копит армию, с 4.5 минуты шлёт волны (каждые 2.5 мин, растут), обороняется.
- A* по сетке (8 направлений без срезания углов, сглаживание), расталкивание, туман (не открыто / видели / видно).

## Управление
- **Мышь:** ЛКМ — выбор; рамка — группа; Shift — добавить/снять; двойной клик — все такие же на экране; ПКМ — идти / атаковать / копать / везти на плавильню (у выбранного Барака/Мастерской — точка сбора); курсор меняется (идти, атака, кирка, «нельзя»). Камера: край экрана, стрелки/WASD, колесо (Shift — по горизонтали), средняя кнопка, клик/протяжка по мини-карте; ПКМ по мини-карте — приказ.
- **Клавиши:** Ctrl+1…9 (или Alt+1…9) — назначить группу, 1…9 — вызвать, дважды — камера к группе; H — к Конторе; X — стоп; Пробел — к выделенным; Esc — отменить постановку/метку; Q / E — способности героев (кампания); P пауза (там же «Заново»), T тема, L язык, M звук.
- **Тач:** тап — выбор, протяжка — рамка, долгий тап — приказ, два пальца — камера; кнопки панели — тапом, долгий тап — отмена.

## Кампания (вертикальный срез)
- **Экраны:** карта кампании (10 миссий, открываются по порядку; 3–10 — заглушки «в работе»), брифинг (мини-карта + пиктограммы целей + 1–2 фразы RU/EN, отряд, ветераны), итог (звёзды, время, потери, флаги, «Далее»). Прогресс — `localStorage['arcade.priisk.campaign']` (try/catch; без хранилища игра работает, прогресс не сохраняется). Сброс — кнопка на карте кампании (двойное нажатие).
- **Миссия 1 «Первая заявка»** — обучение: Котельная → Плавильня → рудовоз привёз медь → Барак → 4 стрелка (подсказки-цели, подсветка нужной кнопки, круг на карте). Ночь — по готовности (обучены стрелки) или на 9-й минуте: обзор урезан, приходит «проверка» Сизых (5 стрелков) — первая оборона. Звёзды: выполнено · без потерь зданий · за 15 минут. Поражение — пала Контора.
- **Миссия 2 «Разведка в метели»** — Луня, Варвара и 5 стрелков без базы. Метель волнами (обзор ×0.4…0.85, период 50 с). Найти лагерь Сизых (увидеть его — дойти или поставить метку Луни) и вернуть Луню к саням. Посты, патруль, засада в ущелье по триггеру; за спиной трескается лёд переправы — назад только через северный брод. Обоз Сизых (сани + охрана): отбить или тихо обойти → флаг `flags.convoy` = `raided` / `escaped` / `sneaked` (для миссии 4; виден на экране итога и на карте кампании). **Гибель Луни — поражение.** Звёзды: выполнено · вернулись все · за 12 минут.
- **Герои:** Варвара Клин — аура боевого духа (стрелки рядом: урон ×1.25, скорость ×1.15), **Q — «Клич»** (8 с: радиус ×1.6, урон ×1.5, скорость ×1.3; перезарядка 30 с). Луня — обзор 9, **E — «Метка»** (ЛКМ по карте или мини-карте в пределах 18 клеток: туман открыт радиусом 6 на 12 с; перезарядка 25 с). Кнопки способностей — в панели. Гибель героя не провал (кроме обязательных): Варвара в следующей миссии приходит раненой (60% здоровья).
- **Ветераны:** 3 победы — звание (шеврон, урон ×1.2). Выжившие ветераны и состояние героев переносятся в следующую миссию.
- **Движок миссий** (`js/campaign.js`, без DOM): миссия — объект в `js/missions/*.js`: ASCII-карта (`#` скала, `~` вода, `=` лёд, `_` полынья, `o`/`O` медь, `.` земля, буквы — именованные точки; `legend` — клетка под буквой), зоны (`{at, r}` / прямоугольник), стартовые силы обеих сторон, медь, разрешённые здания/юниты, цели (основные/по выбору, цепочки `after`, подсказки `hint`), звёзды, условия поражения, **триггеры** (`time`, `zone`, `built`, `units`, `trained`, `mined`, `copper`, `gone`, `killed`, `heroDead`, `obj`, `flag`, `seen`, `alerted`, `all/any/not`) и **действия** (`say`, `msg`, `spawn`, `group`, `despawn`, `tiles` — изменить карту, `reveal`, `objective`, `weather`, `night`, `flag`, `copper`, `win`, `lose`, `wait`, `ai`, `allow`). Сценарный ИИ групп по тегу: `hold`, `patrol`, `attack`, `convoy` (+ реакция на обстрел, `notice`), плюс волновой ИИ скирмиша действием `ai`.
- **Добавить миссию:** скопировать `js/missions/m2.js`, поменять `id`/`n`, карту, цели и триггеры; подключить `<script>` в `index.html` и в список файлов `tests/campaign.test.mjs`.

## Файлы
- `js/mouse.js` — **ArcadeMouse**: модуль мыши/тача без знания об игре (клик/двойной, рамка, ПКМ, захват для панели, средняя кнопка, колесо, край экрана, тач-жесты, SVG-курсоры). Кандидат на вынос в `_shared/`.
- `js/game.js` — логика без DOM (карта, A*, юниты, экономика, туман, ИИ) — `PRIISK.logic`.
- `js/render.js` — рисование (темы modern/retro), мини-карта, панель. `js/main.js` — склейка с движком. `js/i18n.js` — RU/EN.
- `js/campaign.js` — движок миссий (карта, триггеры, действия, сценарный ИИ, погода, итог, прогресс) — `PRIISK.campaign`.
- `js/missions/m1.js`, `js/missions/m2.js` — миссии данными. `js/campaign-ui.js` — экраны кампании и HUD миссии — `PRIISK.campUI`.
- `engine.js` — копия `_shared/engine.js`.

## Тесты
- `node _proto/rts-a/tests/engine.test.mjs` — логика, ArcadeMouse на фейковом canvas, i18n, правило имён (стоп-лист в base64).
- `node _proto/rts-a/tests/browser.mjs [папка]` — Playwright: рамка/ПКМ/двойной клик/группы/курсоры/панель/камера мышью, тач через CDP, 0 ошибок; с папкой — скриншоты `rts-a-{retro,modern}.png` (порт — `PORT`, по умолчанию 8351).
- `node _proto/rts-a/tests/campaign.test.mjs` — парсер карт, триггеры и действия, сценарный ИИ, герои, ветераны, сохранение/флаги/перенос, проходимость (A*), **бот проходит миссию 1 и миссию 2** (оба пути с обозом), тексты RU/EN.
- `node _proto/rts-a/tests/campaign-browser.mjs [папка]` — Playwright мышью: меню → кампания → брифинг → миссия 1 (стройка, цели, ночь, Клич) → миссия 2 (метель, рамка+ПКМ, метка) → итог; 0 ошибок; скриншоты `priisk-m1-*`, `priisk-m2-*` (порт `PORT`, по умолчанию 8353).
