# ЛЕНТОВОД · прототип «фабрика + оборона + армия»

Прототип для оценки (не полная игра) студии «Гефест». Паровая мастерская на рудном поле: медь, уголь и песок,
деревянные ленты с латунными роликами, станки под медными крышами и пар. На востоке — **Ржавый курган**, из него
по таймеру ползёт **Ржавь** (ржавники и ржавые громилы) и грызёт всё на пути к **Мастерской**.
Один сектор 72×44, партия 15–20 минут. Победа — снести курган, поражение — пала Мастерская.

Рабочее название проверено поиском: игры «Лентовод» не нашлось (вариант на английском, похожий на существующую игру, отброшен).

## Запуск
Из корня репо: `python3 -m http.server 8356` → <http://localhost:8356/_proto/fabrika/> (`?lang=en`, `?seed=N`,
`?demo=1` — готовая демо-мастерская у старта и первая волна позже, для показа).

## Правила
- **Добыча:** бур ставится только на жилу и выдаёт руду вперёд по стрелке (1 шт. / 1.2 с).
- **Ленты:** 2 клетки/с, до 3 предметов на клетку. Протяжка мышью кладёт линию «Г» (сначала по длинной оси), повороты — сами.
  Протяжка по своим лентам только меняет направление (бесплатно). Лента не берёт предмет со своего выхода.
- **Развилка:** вход сзади, раздаёт по очереди вперёд / влево / вправо. **Сортировщик:** выбранный предмет — вперёд, остальное — вбок;
  клик по нему без инструмента меняет фильтр. **Мост:** два моста одного направления (через 1–3 клетки) перекидывают предметы над лентой.
- **Станки (2×2)** берут нужное с любой стороны и отдают продукт на соседние ленты, смотрящие наружу (или прямо в станок/пушку/Мастерскую рядом):
  Плавильня — медная руда + уголь → слиток; Стекольня — 2 песка + уголь → стекло; Шестерённая — 2 слитка → шестерня;
  Сборочный цех — 3 слитка + 2 шестерни + стекло → боец **Клёпаный**.
- **Мастерская** — склад: всё, что доехало, идёт в запас, из запаса платится стройка (снос возвращает стоимость). Своя слабая пушка — последний рубеж.
- **Оборона:** паровая пушка стреляет только пока лента подаёт ей слитки (1 слиток = 3 выстрела); частокол держит Ржавь.
  Ржавь идёт к Мастерской по A* (скалы непроходимы, роща — медленно, сквозь постройки — с прогрызанием; частокол «дорогой»).
- **Армия:** клёпаные идут к точке сбора (флаг, F) и отстреливаются; «Вперёд!» (G) — все на курган. Курган отстреливается и
  выпускает охрану, когда бойцы рядом. Волны: первая на 3:00, дальше каждые ~80→55 с, растут.

## Управление
- **Мышь:** ЛКМ — поставить (призрак зелёный/красный), протяжка — линия (лента, частокол), без инструмента — выбор/инфо и
  перетаскивание камеры; ПКМ — снести (протяжка — рамка сноса), по пустому — снять инструмент; колесо — зум к курсору;
  средняя кнопка — камера; клик по мини-карте — камера.
- **Клавиши:** 1–9 — бур, лента, развилка, сортировщик, мост, плавильня, стекольня, шестерённая, сборочный цех; Q — пушка; E — частокол;
  X — снос; F — сбор; G — вперёд; R / Shift+R — поворот; Esc — снять инструмент; WASD/стрелки — камера; Пробел — к Мастерской;
  P пауза (там же «Заново»), T тема, L язык, M звук.
- **Тач:** тап — поставить, протяжка — линия (без инструмента — камера), два пальца — камера и зум; снос и поворот — кнопками панели.

## Файлы
- `js/sim.js` — логика без DOM (`LENTOVOD.sim`): сетка, постройки, передача предметов, станки, пушки, Ржавь, клёпаные, A*, волны, демо-раскладка.
  Фиксированный тик 1/20 с; A* на типизированных массивах с бинарной кучей, пересчёт пути только при изменении построек (`bver`), не больше 8 поисков за тик.
- `js/render.js` — рисование (modern / retro): поле в offscreen-canvas, постройки, предметы, HUD, панель, мини-карта, подсказки.
- `js/pointer.js` — **FabPointer**: мышь/тач без знания об игре (ЛКМ-протяжка, ПКМ-фазы, средняя, колесо, щипок).
- `js/main.js` — склейка с движком: инструменты, призрак, протяжка, снос, камера/зум, звук, сообщения; `LENTOVOD.debug` для тестов.
- `js/i18n.js` — RU/EN; `js/music.js` — тема (ре дорийский, 8 тактов); `engine.js` — копия `_shared/engine.js`.

  4 рецепта, пушка только с боеприпасом, волна по A* до Мастерской, прогрызание частокола, победа/поражение, правила стройки,
  линия, проходимость карты, демо, **производительность** (500 предметов + 40 буров, 2000 тиков ≈ 60 мс), FabPointer, RU/EN, музыка,
  правило имён (стоп-лист в base64: общий список аркады + игры жанра «фабрика/автоматизация»).
- `node _proto/fabrika/tests/browser.mjs [папка]` — Playwright мышью: бур → лента → плавильня (+ уголь) → лента в Мастерскую, слиток доехал;
  ПКМ-снос, колесо, средняя кнопка, Esc; тач через CDP (тап, протяжка, два пальца); P/T/L; 0 ошибок. С папкой — скриншоты
  `fabrika-modern.png`, `fabrika-retro.png` (порт — `PORT`, по умолчанию 8356).
