# РАЗРЕЗ · Отрежь поле

Оригинальная игра студии **«Гефест»** в жанре «отрезания территории».
Чистый HTML5/Canvas на фреймворке Гефест Arcade v2: без сборки, CDN, шрифтов и
ассетов из сети, открывается как `razrez/index.html` (в том числе по `file://`).

Резец ходит по захваченной суше. Уйди в свободное поле — за тобой тянется след.
Вернись на сушу — след замкнётся, и каждая отрезанная часть поля, где нет шаров,
станет твоей. Шар, коснувшийся следа или резца, стоит жизни; свой след пересекать
нельзя. Клещи ползают по суше и тоже опасны. Захвати **75%** поля, чтобы пройти уровень.

- **5 уровней:** шаров 2→6, скорость шаров 7→11 клеток/с, клещей 0→3 (через `g.difficulty`).
- **Жизни:** 3 на старте, +1 за пройденный уровень (не больше 5).
- **Очки:** клетки × уровень, бонус за крупный разрез, бонус за уровень (перебор % и жизни). Рекорд — `localStorage`.
- **Темы:** modern (по умолчанию) и retro (8-бит, 16 цветов, кирпичная суша, сканлайны) — `T`. Меняется только отрисовка.
- **Языки:** RU/EN — `L`. **Звук:** `M` (оригинальные SFX на WebAudio). **Пауза:** `P`/`Esc`.

## Управление

| Действие | Клавиши |
|---|---|
| Ход | `←↑→↓` или `WASD` (в поле резец идёт сам; разворот на 180° со следом запрещён) |
| Старт / выбор в меню | `Enter` / `Пробел` |
| Пауза | `P`, `Esc` |
| Тема / язык / звук | `T` / `L` / `M` |

На телефоне — экранный дпад и кнопка паузы `II`.

## Файлы

- `index.html` — страница, канва, дпад, ссылка «← Каталог».
- `engine.js` — копия `_shared/engine.js` (кладётся `build.sh`).
- `js/game.js` — логика без DOM: сетка, движение, след, заливка, уровни (`RAZREZ.Game`, `RAZREZ.logic`).
- `js/modern.js`, `js/classic.js` — рендеры тем; `js/ui.js` — HUD и баннеры; `js/audio.js` — SFX; `js/i18n.js` — строки RU/EN; `js/main.js` — сцены движка.
- `css/style.css` — стили страницы.

## Тесты

`node razrez/tests/engine.test.mjs` — логика (заливка, процент, столкновения, уровни, победа/поражение).
