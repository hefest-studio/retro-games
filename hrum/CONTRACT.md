# КАТЫШ — HTML5: стандарт игры аркады «Гефест»

Оригинальная игра студии **«Гефест»** (папка `hrum`, EN — SEEDGLIDE). Открывается как `hrum/index.html` по `file://` — **без сборки, CDN, npm и интернета**.
Весь контент рисуется/синтезируется кодом: нет внешних картинок, шрифтов и аудиофайлов. Описание игры, правила и переделка — в `README.md`.

## Модули
- `js/game.js` — `KATYSH.Game` (DOM-free; состояние — чистые данные, `clone()`), `KATYSH.level(i)` (карта, семечки, коты), `KATYSH.analyze` (граф остановок), `KATYSH.consts`.
- `js/render.js` — `KATYSH.render` (pal/geo/pt/bare/draw), обе темы; в альбоме мир повёрнут на 90°.
- `js/main.js` — сцены движка, ввод, площадка (лидерборд `hrum`, `useNoAds`, награда, `adBreak`), миграция (`js/save.js`).
- `js/i18n.js`, `js/audio.js`, `js/music.js` (трек `Arcade.tracks.hrum`), `js/ui.js` (ориентация/подгонка), `js/stick.js` (копия `otsek/js/stick.js`).

## Общий стандарт аркады «Гефест» (инвариант для всех игр)
- Полностью **офлайн**, без сборки/CDN/npm/сети и внешних ассетов.
- Две темы (**retro** / **modern**, `T`), локализация RU/EN/TR/ES/PT через `g.t`; звук и музыка — только WebAudio, оригинальные.
- Ввод по `e.code` (работает кириллица); рекорд и настройки — в `localStorage` (`arcade.best.hrum`, `arcade.hrum.*`).
- Код: `'use strict'`, без `import/export`/`fetch`/внешних URL; комментарии по-русски.
- **Авторские права:** названия, спрайты, музыка и палитры — оригинальные.

## Definition of Done
- Титул → игра → пауза → конец/победа → рестарт; обе темы и пять языков; мобильный стик и геймпад; портрет и 16:9.
- Нет ошибок в консоли; `node hrum/tests/engine.test.mjs` и `node tools/smoke.mjs` проходят.
