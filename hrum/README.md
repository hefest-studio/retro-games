# ХРУМ · Лабиринт

Оригинальная аркада-лабиринт студии **«Гефест»** по мотивам жанра 1980-х.
Чистый HTML5/Canvas, без сборки, CDN и внешних ассетов — открывается как `hrum/index.html`.

Герой-грызун собирает кристаллы в лабиринте и убегает от четырёх врагов-кристаллов;
усилитель на время делает врагов уязвимыми. Туннель по краям, уровни, жизни.

- **Два стиля:** 8-бит и неон (кнопка «Графика» / клавиша `G`).
- **Языки:** RU/EN (`L`). **Звук:** `M`. **Пауза:** `P`.
- **Управление:** стрелки или WASD.
- Оригинальный чиптюн и SFX на WebAudio. Рекорд хранится локально (localStorage).

Враги ведут себя по-разному (разгон по углам → погоня → испуг после усилителя) —
классическая динамика «кота-мышки» без копирования конкретных образов.

Автотесты движка: `node hrum/tests/engine.test.mjs` (12/12).
